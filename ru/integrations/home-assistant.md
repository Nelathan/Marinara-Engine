# Интеграция с Home Assistant

В этом руководстве вы узнаете, как подключить приложение Marinara Engine к Home Assistant. После подключения персонажи ИИ смогут управлять настоящими устройствами умного дома прямо из чата. Им доступны свет, климат, шторы и медиаплееры. Кроме того, автоматизации Home Assistant смогут отправлять сообщения в приложение Marinara.

Home Assistant – это бесплатная платформа с открытым исходным кодом для управления устройствами умного дома. Если вы не пользуетесь Home Assistant, эта интеграция не нужна.

## Что делает эта интеграция

Интеграция – это небольшая программа, которая устанавливается внутрь Home Assistant. Она связывает работающий Home Assistant с работающим сервером Marinara Engine. После установки она автоматически делает три вещи:

- Создает инструменты умного дома в приложении Marinara. Они появляются в разделе **Functions** (функции) панели Presets. В приложении Marinara они называются "custom tools" или "Functions". О том, как функции работают в целом, читайте в руководстве [Собственные инструменты и вызов функций](../extending/custom-tools.md).
- Создает в приложении Marinara одного агента ИИ с названием **Home Assistant**. Агент – это помощник на базе ИИ, который работает рядом с чатом. См. [Агенты: помощники ИИ в чатах](../agents/agents-overview.md).
- Создает несколько сущностей Home Assistant, чтобы за приложением Marinara можно было следить и управлять им со стороны Home Assistant. Сущность – это устройство, датчик или элемент управления в Home Assistant.

Адреса инструментов копировать не нужно, настраивать инструменты вручную тоже. Интеграция связывает все между собой при первой настройке.

## Что нужно заранее

Перед началом проверьте, что есть все перечисленное ниже.

- Работающий Home Assistant версии 2024.1.0 или новее.
- Установленный в Home Assistant HACS. HACS – это Home Assistant Community Store, магазин для установки сторонних интеграций, которых нет в комплекте.
- Установленное и запущенное приложение Marinara Engine, доступное с машины, где работает Home Assistant. Адрес по умолчанию – `localhost:7860`. Если Home Assistant работает на другом устройстве, прочитайте примечание о паролях ниже.
- Настройка `WEBHOOK_LOCAL_URLS_ENABLED=true`, добавленная в файл `.env` сервера Marinara.

Файл `.env` – это обычный текстовый файл настроек сервера Marinara. Где он лежит и как его редактировать, описано в руководстве [Настройки сервера: справочник](../CONFIGURATION.md).

Последняя настройка нужна потому, что интеграция использует вебхук. Вебхук – это веб-адрес, по которому одно приложение автоматически отправляет данные другому. Адрес вебхука в Home Assistant – локальный, с обычным `http`. Из соображений безопасности приложение Marinara по умолчанию блокирует обращения к локальным адресам `http`. Настройка `WEBHOOK_LOCAL_URLS_ENABLED=true` их разрешает.

Добавьте эту строку в файл `.env`:

```
WEBHOOK_LOCAL_URLS_ENABLED=true
```

Настройка применяется в течение пары секунд. Перезапускать сервер Marinara не нужно.

### Если Home Assistant работает на другом устройстве

Интеграция подключается к приложению Marinara без имени пользователя и пароля. В форме настройки их просто негде указать. Поэтому важно, где именно работает Home Assistant:

- Если Home Assistant и приложение Marinara работают на одной машине, подключение заработает сразу.
- Если Home Assistant работает на другом устройстве, приложение Marinara по умолчанию блокирует подключение. Устройству с Home Assistant нужно разрешить подключаться без пароля. Один из способов – добавить IP-адрес этого устройства в `IP_ALLOWLIST` в файле `.env` сервера Marinara. IP-адрес – это числовой адрес устройства в сети. В полностью доверенной домашней сети вместо этого можно задать `ALLOW_UNAUTHENTICATED_PRIVATE_NETWORK=true`.
- Если приложение Marinara защищено параметрами `BASIC_AUTH_USER` и `BASIC_AUTH_PASS`, интеграция не сможет войти. Тогда она работает только с той же машины или с устройства, указанного в `IP_ALLOWLIST`.

Как работают эти настройки и какую из них выбрать, описано в руководстве [Удаленный доступ: Basic Auth и список разрешенных адресов](../REMOTE_ACCESS.md).

## Установка интеграции в Home Assistant

Установка проходит в два этапа. Сначала интеграция добавляется в HACS, затем настраивается.

### Добавление в HACS

1. В Home Assistant откройте **HACS**.
2. Откройте меню из трех точек и нажмите **Custom repositories** (сторонние репозитории).
3. В поле репозитория введите этот адрес:

```
https://github.com/Pasta-Devs/Marinara-Engine
```

4. Задайте категорию **Integration** (интеграция), затем нажмите кнопку **Add**.
5. Найдите **Marinara Engine** и установите.
6. Перезапустите Home Assistant.

### Настройка

1. Откройте **Settings** (настройки), затем **Devices & Services** (устройства и службы), и нажмите кнопку **Add Integration** (добавить интеграцию).
2. Найдите **Marinara Engine**.
3. Укажите в полях **Host** (адрес) и **Port** (порт), где работает приложение Marinara. По умолчанию это `localhost` и `7860`.
4. Нажмите кнопку **Submit**.

Если приложение Marinara недоступно по этому адресу, Home Assistant покажет ошибку и не завершит настройку. См. раздел "Устранение неполадок" ниже.

## Что приложение Marinara Engine создает автоматически

После успешной настройки интеграция собирает все необходимое сама.

- Регистрирует внутри Home Assistant частный вебхук.
- Создает инструменты умного дома в разделе **Functions** приложения Marinara, и каждый из них уже нацелен на этот вебхук.
- Создает в приложении Marinara агента **Home Assistant** со списком всех включенных инструментов.
- Создает сущности Home Assistant, описанные далее в этом руководстве.

## Добавление агента Home Assistant в чат

Созданный агент не подключается ко всем чатам сразу. Его нужно добавить в каждый чат, где нужно управление умным домом.

1. Откройте нужный чат.
2. Откройте **Chat Settings** (настройки чата), затем раздел **Agents** (агенты).
3. Добавьте в чат агента **Home Assistant**.

Агент Home Assistant работает в чатах Roleplay, Conversation и Game. После добавления инструменты умного дома становятся доступны ИИ в этом чате автоматически. Больше ничего включать в чате не нужно.

## Проверка работы

Проверьте подключение одним простым запросом.

1. Добавьте агента **Home Assistant** в чат, как показано выше.
2. В этом чате напишите обычную просьбу, например: `Turn on the office lights`.
3. Отправьте сообщение.

ИИ должен вызвать инструмент умного дома, например `ha_turn_on`, и нужный свет включится. Затем ИИ сообщает, что именно сделал. Если ничего не произошло, проверьте, что задана настройка `WEBHOOK_LOCAL_URLS_ENABLED=true`, и посмотрите раздел "Устранение неполадок".

## Открытые категории инструментов

Интеграция делит инструменты умного дома на восемь категорий. Какие категории доступны приложению Marinara, решаете вы.

Чтобы изменить набор категорий, откройте **Settings**, затем **Devices & Services**, нажмите **Marinara Engine**, а затем кнопку **Configure** (настроить). Здесь два параметра:

- **Primary Chat** (основной чат): чат по умолчанию, на который направлены службы Home Assistant. Эти службы описаны далее в руководстве.
- **Exposed Tool Categories** (открытые категории инструментов): список категорий инструментов, которые разрешены приложению Marinara.

В таблице перечислены категории, их состояние по умолчанию и входящие в них инструменты.

| Категория | По умолчанию | Инструменты |
|---|---|---|
| Lights & Switches | On | ha_turn_on, ha_turn_off, ha_toggle, ha_set_brightness, ha_set_color, ha_set_color_temp |
| Climate | On | ha_set_temperature, ha_set_hvac_mode |
| Covers (Blinds & Garage) | On | ha_open_cover, ha_close_cover, ha_set_cover_position |
| Locks | Off | ha_lock, ha_unlock |
| Media Players | On | ha_media_play, ha_media_pause, ha_set_volume |
| Scenes & Scripts | On | ha_activate_scene, ha_run_script |
| Query | On | ha_get_state, ha_list_areas, ha_list_entities, ha_notify |
| Generic Service Calls (Advanced) | Off | ha_call_service |

Категории **Locks** и **Generic Service Calls (Advanced)** по умолчанию выключены. Включайте их только в том случае, если они действительно нужны. Категория **Generic Service Calls (Advanced)** позволяет ИИ вызвать любую службу Home Assistant, поэтому обращайтесь с ней осторожно.

Большинство инструментов принимает либо конкретное устройство, либо название комнаты. Если указано название комнаты, инструмент срабатывает сразу для всех подходящих устройств в этой комнате.

Изменения категорий вступают в силу только после нажатия кнопки **Marinara Sync HA Tools** (синхронизировать инструменты HA) или перезапуска Home Assistant. Эта кнопка описана в следующем разделе.

## Сущности Home Assistant

Интеграция создает эти сущности внутри устройства Home Assistant с названием **Marinara Engine**.

| Сущность | Тип | Что делает |
|---|---|---|
| Marinara Chat Count | Sensor | Показывает общее число чатов в приложении Marinara |
| Marinara Active Agent Count | Sensor | Показывает, сколько агентов Marinara включено |
| Marinara Active Chat | Select | Выбирает чат, на который направлены службы Home Assistant |
| Marinara Agent: (name) | Switch | Включает или выключает одного агента Marinara. Для каждого агента есть свой переключатель |
| Marinara Abort Generation | Button | Отменяет любой ответ ИИ, который сейчас генерируется |
| Marinara Sync HA Tools | Button | Заново отправляет все инструменты и пересобирает агента Home Assistant |

Интеграция проверяет приложение Marinara на новые чаты и агенты каждые 30 секунд. Чат или агент, только что созданный в приложении Marinara, может появиться здесь с задержкой до 30 секунд.

## Управление приложением Marinara из автоматизаций Home Assistant

Интеграция добавляет две службы Home Assistant. Они используются в автоматизациях Home Assistant, а не в приложении Marinara. По умолчанию обе работают с чатом **Primary Chat**.

### Служба Send Message (marinara_engine.send_message)

Она отправляет сообщение в чат Marinara.

- `message`: текст сообщения. Обязательное поле.
- `chat_id`: чат, куда отправить. Если оставить поле пустым, используется чат Primary Chat.
- `role`: от кого сообщение. Возможные значения: `user`, `assistant`, `system` или `narrator`. По умолчанию – `user`.
- `trigger_generation`: если true, после отправки сообщения ИИ еще и отвечает. По умолчанию – false.

Вот автоматизация, которая сообщает ИИ об открытии входной двери:

```yaml
automation:
  trigger:
    platform: state
    entity_id: binary_sensor.front_door
    to: "on"
  action:
    service: marinara_engine.send_message
    data:
      message: "Someone just arrived at the front door."
      trigger_generation: true
```

### Служба Trigger Generation (marinara_engine.trigger_generation)

Она запускает ответ ИИ в чате без видимого сообщения от вас.

- `chat_id`: какой чат использовать. Если оставить поле пустым, используется чат Primary Chat.
- `user_message`: необязательное сообщение, которое добавляется к ходу с ответом.

## Повторная синхронизация после изменения настроек

После изменения набора включенных категорий нажмите кнопку **Marinara Sync HA Tools**, чтобы применить изменения. Эта кнопка находится на странице устройства **Marinara Engine** в Home Assistant.

Нажатие кнопки **Marinara Sync HA Tools** делает следующее:

- Обновляет существующие инструменты на месте, так что все изменения доходят до приложения Marinara.
- Пересобирает агента **Home Assistant**, если он был удален в приложении Marinara.
- Выключает все инструменты из категорий, которые вы отключили. Сами инструменты при этом не удаляются.

Не правьте инструменты Home Assistant в приложении Marinara вручную. Следующая синхронизация перезапишет правки и снова включит инструменты.

## Устранение неполадок

### Форма настройки сообщает, что не может подключиться

Проверьте, что приложение Marinara Engine запущено. Убедитесь, что значения в полях **Host** и **Port** совпадают с адресом, на котором оно слушает. По умолчанию это `localhost` и `7860`.

Если Home Assistant работает не на той машине, где приложение Marinara, оно по умолчанию блокирует его. Интеграция не умеет передавать пароль, поэтому приложение Marinara должно принимать это устройство без пароля. Добавьте IP-адрес устройства с Home Assistant в `IP_ALLOWLIST` в файле `.env` сервера Marinara. Об этом и о других вариантах читайте в руководстве [Удаленный доступ: Basic Auth и список разрешенных адресов](../REMOTE_ACCESS.md). Приложение Marinara, защищенное параметрами `BASIC_AUTH_USER` и `BASIC_AUTH_PASS`, тоже отклоняет интеграцию – если только устройство не указано в `IP_ALLOWLIST`.

Эти правила действуют и после настройки. Если приложение Marinara позже заблокирует устройство с Home Assistant, датчики и список чатов молча перестанут обновляться.

### ИИ вызывает инструмент устройства, но ничего не происходит

Скорее всего, обращение к вебхуку заблокировано. Добавьте `WEBHOOK_LOCAL_URLS_ENABLED=true` в файл `.env` сервера Marinara и сохраните его. Настройка применяется в течение пары секунд. Без нее вызовы инструментов могут завершаться ошибкой о том, что `http` не разрешен, или об отказе для частного адреса.

Если приложение Marinara и Home Assistant работают на одной машине, интеграция автоматически подставляет для вебхука внутренний адрес. Если приложение Marinara работает на другом устройстве, проверьте, что локальный сетевой адрес Home Assistant доступен с этого устройства.

### Инструменты не появляются в списке Functions

Нажмите кнопку **Marinara Sync HA Tools** или перезапустите Home Assistant. Затем проверьте раздел **Functions** в панели Presets приложения Marinara.

### Агента Home Assistant нет в чате

Сначала убедитесь, что агент **Home Assistant** есть в приложении Marinara в разделе Agents. Если его нет, нажмите кнопку **Marinara Sync HA Tools**, чтобы пересобрать его. Затем откройте **Chat Settings**, откройте раздел **Agents** и добавьте агента **Home Assistant** в этот чат.

### Как найти адрес вебхука вручную

Это редко нужно, потому что адрес уже прописан в каждом инструменте. Чтобы его найти, откройте в Home Assistant **Settings**, затем **Devices & Services**, затем **Marinara Engine**. Адрес вебхука строится по такому шаблону, где 8123 – это порт Home Assistant по умолчанию:

```
http://<homeassistant-ip>:8123/api/webhook/<webhook-id>
```

## Удаление интеграции

Чтобы убрать интеграцию, откройте в Home Assistant **Settings**, затем **Devices & Services**, затем **Marinara Engine** и удалите ее оттуда. Сущности Home Assistant при этом исчезнут. Инструменты, созданные в разделе **Functions** приложения Marinara, остаются в приложении Marinara. Агент **Home Assistant** тоже остается. Если они больше не нужны, удалите и то и другое вручную в приложении Marinara.
