# Руководство по установке на Windows

В этом руководстве вы узнаете, как установить Marinara Engine на Windows. Есть два пути: установщик в один клик (простой вариант) или сборка из исходного кода. Здесь же описаны системные требования, дополнительные возможности и порядок обновления.

## Системные требования

Marinara Engine работает на вашем компьютере с Windows. Понадобится следующее:

- Windows 10 или Windows 11 (64 бита).
- Несколько гигабайт свободного места на диске для приложения и его зависимостей.
- Подключение к интернету во время установки (нужно скачать код и пакеты).

Для обоих способов нужны две программы. Установщик может получить их сам. При установке из исходного кода их ставят вручную:

- **Node.js** версии 24, 25 или 26. Node.js запускает приложение. Рекомендуемый выпуск LTS – версия 24. LTS означает Long Term Support, то есть длительную поддержку стабильной версии.
- **Git**. Git скачивает код и позволяет приложению обновляться в дальнейшем.

pnpm – это менеджер пакетов, который устанавливает составные части приложения. При установке через установщик или через скрипт запуска **start.bat** ставить pnpm вручную не нужно. Оба способа сами получают нужную версию pnpm через Corepack (это вспомогательная программа для pnpm, входящая в Node.js) или через временное скачивание. Команда `pnpm` в системе нужна только при ручной настройке без скрипта запуска. Шаг установки описан в том разделе.

## Способ 1: установщик для Windows (рекомендуется)

Проще всего начать с установщика. Он проверяет наличие Node.js и Git, помогает поставить их, если их нет, скачивает приложение, собирает его и создает ярлыки.

Порядок действий:

1. Откройте в браузере страницу выпусков Marinara Engine.

```text
https://github.com/Pasta-Devs/Marinara-Engine/releases
```

2. Скачайте с этой страницы последний файл установщика для Windows.
3. Запустите установщик и выполняйте указания на экране. Если Node.js или Git отсутствуют, разрешите установщику поставить их.
4. Укажите папку установки, когда об этом спросят, или оставьте предложенную.
5. Дождитесь, пока установщик скачает приложение и соберет его. Это может занять несколько минут.
6. После завершения дважды щелкните новый ярлык на рабочем столе, чтобы запустить Marinara Engine.

Через небольшую задержку браузер должен открыть приложение. Если этого не произошло, откройте браузер и перейдите по адресу:

```text
http://127.0.0.1:7860
```

Установщик создает копию приложения под управлением Git. Благодаря этому приложение может обновляться само при следующем запуске. См. раздел про обновление ниже.

Если антивирус предупреждает об установщике, это известное ложное срабатывание. Установщик скачивает Node.js и Git, и некоторые антивирусы считают такое поведение подозрительным. Запускайте установщик только в том случае, если скачали его с официальной страницы выпусков по ссылке выше.

## Способ 2: установка из исходного кода

Этот способ подойдет, если вы предпочитаете вводить команды сами или хотите тестовую версию (staging).

### Шаг 1: установка Node.js и Git

1. Скачайте установщик Node.js с официального сайта и запустите его.

```text
https://nodejs.org/en/download
```

2. Скачайте установщик Git с официального сайта и запустите его.

```text
https://git-scm.com/download/win
```

3. Откройте новое окно Command Prompt. Проверьте, что версия Node.js – 24, 25 или 26:

```bat
node -v
```

4. Проверьте, что Git установлен:

```bat
git --version
```

Каждая команда должна вывести номер версии. Если команда не найдена, закройте и снова откройте Command Prompt или переустановите отсутствующую программу.

### Шаг 2: скачивание кода и запуск

Скрипт запуска **start.bat** делает настройку за вас. Он выбирает нужную версию pnpm, устанавливает зависимости, собирает приложение и открывает браузер.

1. Скачайте код с помощью Git:

```bat
git clone https://github.com/Pasta-Devs/Marinara-Engine.git
```

2. Перейдите в новую папку:

```bat
cd Marinara-Engine
```

3. Необязательный шаг: переход на тестовую версию. Скачивается стабильная версия. Если вместо нее нужна тестовая версия (staging), выполните эту команду до первого запуска. Для стабильной версии шаг можно пропустить. Перед работой с тестовыми сборками сделайте резервную копию данных.

```bat
git checkout staging
```

После такого перехода скрипт запуска оставляет вас на тестовой версии и при обновлениях.

4. Запустите скрипт запуска:

```bat
start.bat
```

Первый запуск занимает несколько минут, потому что все устанавливается и собирается. Когда приложение будет готово, браузер откроет его по адресу `http://127.0.0.1:7860`. Чтобы запустить приложение в дальнейшем, снова выполните **start.bat** из той же папки.

По умолчанию скрипт запуска открывает приложение для локальной сети, поэтому другие устройства в сети тоже могут к нему подключиться. См. раздел про доступ с другого устройства ниже.

### Ручная настройка без скрипта запуска

Если вместо **start.bat** вы хотите вводить каждую команду сами, выполняйте их внутри папки `Marinara-Engine`.

1. Установите pnpm. Этот путь обходится без скрипта запуска, поэтому команда `pnpm` должна быть в системе. Команда `npm` поставляется вместе с Node.js. Выполните один раз:

```bat
npm install -g pnpm
```

2. Установите зависимости:

```bat
pnpm install --force
```

3. Соберите приложение:

```bat
pnpm build
```

4. Запустите сервер:

```bat
pnpm start
```

5. Откройте приложение в браузере:

```text
http://127.0.0.1:7860
```

Все работает на вашем компьютере. При ручной настройке приложение слушает адрес `127.0.0.1`, то есть доступно только с этого компьютера. Чтобы разрешить подключение другим устройствам в сети, создайте файл `.env` в папке `Marinara-Engine`. Добавьте в него такую строку и перезапустите сервер:

```env
HOST=0.0.0.0
```

## Дополнительно: удаление фона у спрайтов средствами ИИ

Marinara Engine запрашивает прозрачный фон для генерируемых статичных спрайтов, а для однотонного цветного фона и белого фона старых картинок в приложении есть встроенная адаптивная очистка. Для детализированных пейзажей и других неоднородных фонов можно дополнительно установить инструмент `backgroundremover`. Он не обязателен, потому что скачивает большие файлы машинного обучения.

Сначала понадобится Python. Установите Python 3.11 с официального сайта, а затем выполните команду установки из папки `Marinara-Engine`:

```text
https://www.python.org/downloads/windows/
```

Выполните шаг установки:

```bat
pnpm backgroundremover:install
```

Команда создает отдельную папку Python (venv) внутри папки с данными. После этого Marinara Engine использует ее для очистки спрайтов автоматически. venv – это изолированная установка Python, которая не влияет на остальную систему.

Другой вариант: пусть **start.bat** установит инструмент при следующем запуске. Добавьте эту строку в файл `.env`:

```env
BACKGROUNDREMOVER_AUTO_INSTALL=true
```

## Обновление Marinara Engine

Чаты, персонажи и настройки при обновлении остаются на месте. Обновить Marinara Engine на Windows можно тремя способами.

### Автоматическое обновление через скрипт запуска

При запуске приложения ярлыком с рабочего стола или через **start.bat** из копии под управлением Git скрипт запуска сначала проверяет обновления. Если есть более новая версия, он скачивает изменения, переустанавливает зависимости, пересобирает приложение и только затем запускает его. Это работает и для установки через установщик, и для копии, полученной вручную.

Чтобы пропустить одну проверку, запустите `start.bat --skip-update`. Чтобы установленная версия сохранялась между запусками, добавьте `AUTO_UPDATE_ENABLED=false` в файл `.env`. Проверка вручную, применение обновления из приложения и обновление через Git при этом остаются доступны.

Если в коде есть несохраненные локальные изменения, скрипт запуска пытается аккуратно их отложить. После обновления он возвращает их на место. Если это не удается, он оставляет текущую версию и выводит сообщение.

### Обновление из приложения

Проверить обновления можно и внутри приложения.

1. Откройте панель **Settings** (настройки).
2. Перейдите на вкладку **Advanced** (дополнительно).
3. Найдите раздел **Updates** (обновления).
4. Выберите канал в раскрывающемся списке **Release Channel** (канал выпусков). Вариант **Latest Stable** – это обычная версия, а **Staging/UAT** – ранние тестовые сборки. Перед работой с тестовыми сборками сделайте резервную копию данных.
5. Нажмите кнопку **Check for Updates** (проверить обновления). Приложение сообщит, есть ли более новая версия.

Кнопка **Apply Update** (применить обновление) для безопасности по умолчанию выключена. Чтобы применять обновление прямо из приложения, нужна дополнительная настройка. Задайте в файле `.env` такие значения:

```env
UPDATES_APPLY_ENABLED=true
ADMIN_SECRET=your-own-secret-value
```

Затем откройте панель **Settings**, перейдите на вкладку **Advanced**, найдите раздел **Admin Access** (доступ администратора) и вставьте туда то же секретное значение. После этого кнопка **Apply Update** становится доступна.

Если приложение открыто с iPhone или iPad, который подключается к этому компьютеру с Windows, кнопка **Apply Update** обновляет именно этот сервер на Windows. Для удаленного применения нужно еще одно значение в файле `.env`:

```env
UPDATES_ALLOW_REMOTE_APPLY=true
```

Если применение обновления из приложения не включено, для обновления достаточно перезапустить приложение ярлыком или через **start.bat**.

### Обновление вручную

Копию под управлением Git без скрипта запуска можно обновить вручную. Выполняйте команды из папки `Marinara-Engine`.

1. Получите последний стабильный код:

```bat
git fetch origin +refs/heads/main:refs/remotes/origin/main
```

2. Перейдите на последнюю стабильную версию:

```bat
git merge --ff-only origin/main || git checkout --detach origin/main
```

3. Переустановите зависимости:

```bat
pnpm install --force
```

4. Пересоберите приложение:

```bat
pnpm build
```

5. Снова запустите сервер:

```bat
pnpm start
```

Для тестовых сборок нужна ветка staging. Выполните эти две команды вместо шагов 1 и 2 выше. Затем продолжайте с установки зависимостей и сборки:

```bat
git fetch origin +refs/heads/staging:refs/remotes/origin/staging
```

```bat
git checkout -B staging origin/staging
```

## Если что-то не работает

Если установка или запуск не удались, сначала проверьте, что версия Node.js – 24, 25 или 26 и что Git установлен. Если антивирус блокирует установщик или скачивание, это известное ложное срабатывание, о котором сказано выше.

Другие решения описаны в руководстве [Устранение неполадок в приложении Marinara Engine](../TROUBLESHOOTING.md).
