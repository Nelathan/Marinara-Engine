# Импорт и экспорт лорбуков

В этом руководстве вы узнаете, как перенести лорбуки в приложение Marinara Engine и как сохранить их обратно в файлы. Речь пойдет об одиночных файлах, о нескольких файлах сразу и о двух форматах экспорта. Лорбук – это набор заметок с ключевыми словами: как только в тексте появляется подходящее слово, Marinara добавляет заметку в промпт для ИИ (промпт – это текст, который Marinara отправляет ИИ). В некоторых других приложениях для ролевых игр эта возможность называется **World Info**.

## Что можно импортировать

Marinara читает лорбуки двух видов и сама определяет, какой файл ей дали:

- Лорбук, экспортированный из приложения Marinara. В нем сохраняются все поля и все папки.
- Файл **World Info** из другого приложения. Сюда входят файлы World Info из SillyTavern и формат "character-book" из карточек персонажей V2. Marinara сопоставляет поля другого приложения со своими.

Файлы обоих видов – это обычные файлы `.json`. Для импорта лорбука не нужны ни аккаунт, ни ключ API (секретный код, похожий на пароль).

## Импорт лорбука

Чтобы импортировать один файл лорбука, выполните эти шаги.

1. Откройте панель **Lorebooks** (лорбуки) слева в приложении.
2. Нажмите иконку со стрелкой вниз в верхнем ряду кнопок. Ее всплывающая подсказка читается **Import** (импорт). Она стоит между иконкой с плюсом (**New** – создать) и иконкой с галочкой (**Select** – выбрать). У всех трех кнопок только иконки, поэтому наведите на них курсор, чтобы увидеть названия.
3. Откроется окно **Import Lorebook** (импорт лорбука). В нем видна область с надписью **Drop one or more lorebook files here or click to browse**.
4. Перетащите файл `.json` на эту область или нажмите на нее и выберите файл.
5. Дождитесь результата. Для каждого файла появляется либо зеленая галочка с надписью **Imported lorebook**, либо красная отметка с сообщением об ошибке.
6. Нажмите кнопку **Close** (закрыть). Новый лорбук появляется в списке панели **Lorebooks**.

Датой создания лорбука Marinara оставляет дату из самого файла, а не момент импорта.

## Импорт нескольких лорбуков сразу (массовый импорт)

Окно **Import Lorebook** принимает за один раз больше одного файла.

1. Откройте панель **Lorebooks** и нажмите иконку со стрелкой вниз. Ее всплывающая подсказка читается **Import**.
2. Перетащите на область для файлов сразу несколько файлов `.json` или нажмите на область и выделите несколько файлов.
3. Marinara импортирует файлы по очереди и показывает строку результата для каждого. Итоговая строка сообщает, сколько файлов прошло успешно, а сколько с ошибкой.

В одной партии можно смешивать файлы Marinara и файлы **World Info**. Marinara проверяет каждый файл отдельно.

## Экспорт лорбука

При экспорте один лорбук сохраняется в файл на устройстве. Так его удобно передать другим или перенести в другую установку приложения.

1. В панели **Lorebooks** нажмите на лорбук, чтобы открыть редактор.
2. Нажмите иконку экспорта в заголовке редактора. Ее всплывающая подсказка читается **Export lorebook** (экспорт лорбука).
3. Откроется окно **Export Lorebook** с двумя вариантами. Выберите один:
   - Формат **Marinara Native** сохраняет папки Marinara и все поля записей. Он нужен, чтобы перенести лорбук в другую установку приложения Marinara без потерь. Имя файла заканчивается на `.marinara.json`.
   - Формат **Compatible JSON** сохраняет файл **World Info** без папок, чтобы его прочитали другие приложения для ролевых игр. Часть деталей, которые есть только в Marinara, при этом теряется. Имя файла заканчивается на `.json`.
4. Браузер скачивает файл.

Выбирайте **Marinara Native**, если файл предназначен для Marinara. Выбирайте **Compatible JSON**, если файл предназначен для другого приложения.

## Экспорт нескольких лорбуков сразу (массовый экспорт)

Несколько лорбуков можно сохранить в один архив zip.

1. В панели **Lorebooks** нажмите иконку с галочкой в верхнем ряду кнопок. Ее всплывающая подсказка читается **Select**.
2. Отметьте флажком каждый лорбук, который нужно экспортировать.
3. Нажмите кнопку **Export** (экспорт) на панели выделения снизу.
4. Браузер скачивает один архив zip с именем `marinara-lorebooks.zip`.

Массовый экспорт всегда использует формат **Marinara Native**, поэтому такие файлы возвращаются в Marinara без потерь.

## Импорт целой папки SillyTavern

Шаги выше импортируют файлы лорбуков, которые у вас уже есть. Другой вариант: забрать лорбуки прямо из папки полной установки SillyTavern. Так вместе с ними подтягиваются персонажи, чаты и пресеты. Для этого предусмотрен отдельный мастер настройки, который импортирует папку целиком. См. [Импорт данных из SillyTavern](../data/importing-from-sillytavern.md).

## После импорта

С ключевыми словами импортированный лорбук работает сразу. Если вы пользуетесь семантическим поиском, который подбирает записи по смыслу, после импорта нужно заново построить его векторы. См. [Семантический поиск в лорбуках](semantic-search.md).
