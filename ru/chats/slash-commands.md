# Справочник слеш-команд

Здесь собраны слеш-команды, которые можно набирать в чате приложения Marinara Engine. Слеш-команда – это короткая запись, которая начинается с косой черты: наберите ее в поле сообщения, чтобы быстро что-то сделать. Часть команд меняет то, что вы видите на экране, а часть просит ИИ что-то написать.

## Как работают слеш-команды

Команду наберите в поле сообщения внизу чата и нажмите кнопку **Send** (отправить). Клавиша Enter тоже отправляет сообщение, если для этого режима чата в панели **Settings** (настройки) включен переключатель **Send on Enter** (отправлять по Enter). По умолчанию в чатах **Conversation** Enter отправляет сообщение, а в чатах **Roleplay** переносит строку. Поле сообщения само напоминает о командах. В чате **Roleplay** подсказка в поле читается **Write your response, / for commands**. В чате **Conversation** подсказка содержит имя персонажа, например "Message @Alice, / for commands". Если в чате несколько персонажей, вместо имени показывается название чата.

Как только вы введете косую черту, над полем появится небольшое меню подходящих команд. В каждой строке видны название команды и краткое описание. Нажмите на строку, и команда подставится в поле; дальше добавьте нужный текст и отправьте сообщение.

У многих команд есть короткие варианты записи. Например, `/continue` и `/cont` делают одно и то же. Полный список всегда можно посмотреть прямо в приложении – для этого выполните команду:

```
/help
```

Часть команд работает в браузере и меняет чат сразу, без затрат. Другие команды просят ИИ сгенерировать текст: они обращаются к подключенному провайдеру и могут расходовать токены. Токен – это небольшой кусочек текста, и большинство провайдеров ИИ считают по токенам объем и стоимость. В таблицах ниже указано, что делает каждая команда.

Слеш-команды работают в полях сообщения режимов **Conversation** и **Roleplay**. В режиме **Game** как слеш-команда работает только `/illustrate`. Все остальное, начинающееся с косой черты, отправляется обычным текстом.

Некоторые команды обращаются к номерам сообщений. Первое сообщение чата Marinara считает номером 1, следующее – 2, затем 3 и так далее. Эти номера нужны командам `/goto`, `/hide` и `/unhide`.

## Команды для чата и сообщений

Эти команды помогают управлять чатом и сообщениями в нем. Они работают в чатах **Conversation** и **Roleplay**.

| Команда | Короткие варианты | Что делает |
|---|---|---|
| `/help` | | Показывает список всех слеш-команд. |
| `/continue` | `/cont` | Дописывает текст к последнему ответу ИИ, не отправляя новое сообщение. Настройка **Add a new line before /continue text** в разделе **Settings → General → Responses** задает, начнется ли текст с новой строки после пустой или продолжится прямо с места обрыва. |
| `/goto` | `/jump`, `/scroll` | Прокручивает чат к сообщению с указанным номером. |
| `/hide` | | Скрывает одно или несколько сообщений от ИИ на следующих ходах. |
| `/unhide` | | Возвращает скрытые сообщения в поле зрения ИИ. |
| `/sys` | `/system` | Добавляет системное сообщение. Такая заметка видна в чате и направляет ИИ, но ее не произносит ни один персонаж. |
| `/macros` | `/macro` | Показывает список поддерживаемых макросов промпта, например `{{user}}` и `{{char}}`. |
| `/remind` | `/reminder`, `/timer` | Запускает таймер, а затем публикует в чате напоминание. |

Чтобы перейти к сообщению 27, наберите:

```
/goto 27
```

Команды `/hide` и `/unhide` принимают один номер, диапазон или их сочетание. Вот так скрываются сообщения с 3 по 8:

```
/hide 3-8
```

Для одного сообщения можно написать `/hide 5`, а для нескольких – `/hide 2-5,9,12`. Скрытые сообщения остаются в чате, но ИИ не читает их на следующем ходу. Чтобы вернуть их, укажите такой же набор номеров в команде `/unhide`.

Команда `/remind` принимает время, а затем текст сообщения. В записи времени `h` означает часы, `m` – минуты, `s` – секунды. Этот пример напомнит о деле через 30 минут:

```
/remind 30m check the oven
```

Напоминание живет в сессии браузера, поэтому не закрывайте вкладку до его срабатывания.

## Команды для истории и ролевой игры

Эти команды помогают вести историю, играть за персонажа и добавлять картинки. Большинство из них лучше всего работают в чате **Roleplay**. Исключение – `/scene`, которую запускают из чата **Conversation**.

| Команда | Короткие варианты | Что делает |
|---|---|---|
| `/guided` | `/narrator`, `/narrate`, `/nar` | Направляет следующий ответ ИИ так, как вы описали. |
| `/as` | `/respond` | Публикует сообщение от лица персонажа или просит персонажа ответить. |
| `/emote` | `/emotion`, `/sprite` | Показывает выражения лица персонажа или переключает спрайт. |
| `/roll` | `/r`, `/dice` | Бросает кубики и публикует результат. |
| `/random` | `/rand`, `/event` | Просит ИИ добавить в историю неожиданное событие. |
| `/scene` | `/rp` | Запускается из чата **Conversation**. Начинает новую сцену **Roleplay** как ветку этого чата. |
| `/illustrate` | `/ill` | Генерирует изображение в галерее текущего чата. |
| `/impersonate` | `/imp` | Пишет ответ за вашу персону. |
| `/impersonate_prompt` | `/imp_prompt` | Задает инструкцию, которой команда `/impersonate` пользуется в этом чате. |

Чтобы направить следующий ответ, добавьте описание после `/guided`:

```
/guided make him confess he is lying
```

Команда `/roll` понимает запись броска кубиков. Такая строка бросает два шестигранных кубика:

```
/roll 2d6
```

Можно добавить модификатор, например `/roll 1d20+5`. Если после `/roll` ничего не указано, Marinara бросает `1d20`.

Спрайт – это картинка персонажа с определенным выражением лица. Команда `/emote` переключает, какая из них видна. Наберите `/emote` без дополнений, чтобы увидеть доступные выражения лица, или укажите одно из них:

```
/emote joy
```

Для переключения спрайтов нужен чат **Roleplay**, в котором спрайты уже загружены. Как их добавить, описано в руководстве [Спрайты персонажа (выражения лица и Full-body)](../characters/sprites.md).

Персона – это персонаж, за которого играете вы; в промптах он записывается как `{{user}}`. Команда `/impersonate` пишет ответ вместо вас. После нее можно добавить описание:

```
/impersonate ask about the weather
```

Команды `/impersonate` и `/impersonate_prompt` недоступны в чатах **Conversation**. Подробный разбор направляемой генерации и работы кнопки **Impersonate** есть в руководстве [Направляемая генерация и Impersonate](guided-and-impersonate.md).

## Команды режима Conversation

Эти команды работают только в чате **Conversation**.

| Команда | Что делает |
|---|---|
| `/uno` | Начинает партию в UNO с персонажами этого чата. |
| `/chess` | Начинает партию в шахматы один на один с персонажем. |
| `/poker` | Начинает партию в покер Texas Hold'em с персонажами. |
| `/8ball` | Начинает партию в пул восьмерку один на один с персонажем. Команда `/pool` делает то же самое. |
| `/status` | Задает или сбрасывает статус активности персонажа. |

Команды `/uno`, `/chess`, `/poker` и `/8ball` открывают окно настройки игры. В одном чате идет только одна игра одновременно. Правила и настройки описаны в руководстве [Настольные игры](../conversation/table-games.md).

Команда `/status` переопределяет статус активности персонажа. Статус принимает значения `online`, `idle`, `dnd` (не беспокоить) и `offline`. Слово `clear` убирает переопределение. Так персонаж переводится в статус idle:

```
/status idle
```

Если в чате несколько персонажей, добавьте в конец имя нужного, например `/status online Alice`.
