# Game Mode: виджеты панели HUD

Это руководство объясняет, как работают виджеты панели HUD в режиме Game Mode приложения Marinara Engine. HUD – это heads-up display, то есть небольшие информационные панели у левого и правого края игрового экрана. Здесь описаны типы виджетов, шаг проверки перед началом игры, перемещение и закрепление панелей, а также обмен готовыми наборами виджетов.

## Что такое виджеты панели HUD

Виджеты панели HUD – это небольшие настраиваемые панели, которые следят за важными величинами во время игры: полоса здоровья, счетчик золота, уровень доверия союзника. У каждой игры может быть свой набор виджетов. С трекерами панели HUD в режиме Roleplay они никак не связаны. О полосе трекеров в чатах Roleplay читайте в разделе "Смежные руководства" ниже.

Всего доступно до 4 виджетов. Как распределить их между левой и правой стороной экрана, решаете вы.

Виджеты работают только тогда, когда для игры включен параметр **Custom HUD Widgets** (свои виджеты панели HUD). В мастере настройки он включен по умолчанию. Если параметр включен, Game Master (GM, ведущий игры) на базе ИИ придумывает начальный набор виджетов, пока строит ваш мир.

## Восемь типов виджетов

Типов виджетов восемь. Для каждого созданного виджета GM выбирает тип сам. Если вы собираете виджеты вручную, тип выбираете вы.

| Тип виджета | Что показывает |
|---|---|
| **Progress Bar** | Горизонтальная полоса: значение относительно максимума, например здоровье или выносливость. |
| **Gauge** | Полукруглая шкала: значение относительно максимума. |
| **Relationship Meter** | Полоса с отметками этапов и подписью – подходит для доверия персонажа NPC или для привязанности. |
| **Counter** | Одно большое число: золото, прошедшие дни, число убитых врагов. |
| **Stat Block** | Небольшая сетка из названных полей со значениями: STR и DEX или слово-статус. |
| **List** | Короткий список пунктов с маркерами, например текущие цели. |
| **Inventory Grid** | Сетка ячеек предметов; можно добавить вкладки категорий и количество предметов. |
| **Timer** | Обратный отсчет в минутах и секундах, который может идти в реальном времени. |

## Окно проверки перед сессией

Если свои виджеты созданы, перед первым ходом появляется шаг проверки. Как только вы нажимаете кнопку **Start Game** (начать игру), открывается окно **Review Starting Widgets** (проверка начальных виджетов). В нем перечислены все начальные виджеты – их можно поправить, пока игра не зафиксировала набор.

В этом окне доступны такие действия:

- Кнопка **Edit** (изменить) у виджета меняет начальные значения или переименовывает поля виджета **Stat Block**.
- Кнопка **Remove** (удалить) убирает ненужный виджет.
- Кнопка **Back** (назад) закрывает окно без начала игры.
- Кнопка **Start Game** начинает игру с показанным набором виджетов.

Похожее окно открывается при запуске новой сессии в уже начатой игре. Оно называется **Prepare Next Session Widgets** (подготовка виджетов к следующей сессии), а вместо кнопки **Start Game** там кнопка **Start Next Session** (начать следующую сессию). Кнопка закрытия подписана **Cancel**, а не **Back**.

## Изменение виджета во время игры

По ходу истории GM обновляет значения виджетов сам. Если какое-то обновление пропущено, виджет можно поправить вручную.

1. Найдите панель виджета у левого или правого края экрана.
2. Нажмите кнопку с карандашом (**Edit**) в заголовке виджета.
3. Измените значения в окне редактора. Например, задайте новые **Current value** (текущее значение) и **Maximum value** (максимальное значение) для полосы.
4. Нажмите кнопку **Save Changes** (сохранить изменения).

В заголовке есть еще маленький знак плюса или минуса. Нажатие на заголовок виджета сворачивает и разворачивает его содержимое.

## Перемещение и закрепление панелей

По умолчанию панели виджетов закреплены на месте. В заголовке каждой панели есть иконка замка.

1. Нажмите иконку замка, чтобы открепить панель. Бледный контур покажет, что панель теперь можно двигать.
2. Перетащите панель на новое место.
3. Нажмите иконку замка снова, чтобы закрепить панель.

Чтобы вернуть панель на стандартное место, дважды нажмите ее иконку замка или нажмите клавишу R, когда иконка выделена. Положение и состояние замка каждая панель запоминает отдельно для каждой игры. Между разными играми расположение не переносится.

На телефоне виджеты показываются маленькими плашками вместо полноценных панелей. Нажатие на плашку открывает виджет, а нажатие на `X` закрывает его снова.

## Как собрать свои виджеты

Виджеты можно спроектировать самостоятельно, не поручая это GM. Редактор виджетов открывается в двух местах:

- В мастере настройки игры: включите параметр **Custom HUD Widgets**, затем включите переключатель **Build Widget Setup** (собрать набор виджетов). Редактор появится под переключателем.
- В уже начатой игре: откройте панель **Chat Settings** (настройки чата), затем раздел **Widgets** (виджеты).

В редакторе выберите тип виджета в раскрывающемся списке и нажмите кнопку **Add** (добавить). Для каждого виджета задаются такие параметры:

- **Icon**: короткий символ или эмодзи в заголовке.
- **Label**: название, которое видно сверху виджета.
- **Type**: один из восьми типов виджетов.
- **Side**: **Left HUD** или **Right HUD**.
- **Accent**: цвет виджета.

Ниже у каждого типа свои поля. Полоса использует **Value** и **Max**. Счетчик – **Count**. Сетка инвентаря – **Slots** и **Contents**. Таймер – **Seconds** и **Running**. Редактор показывает, сколько виджетов уже занято из 4 доступных.

В панели **Chat Settings** нажмите кнопку **Save Widgets** (сохранить виджеты), чтобы применить изменения к игре, или кнопку **Reset** (сбросить), чтобы отменить несохраненные правки.

## Обмен виджетами через импорт и экспорт

Набор виджетов можно сохранить в файл и загрузить в другую игру. Эти кнопки есть и в мастере настройки, и в разделе **Widgets** панели **Chat Settings**.

1. Нажмите кнопку **Export Widgets** (экспортировать виджеты), чтобы скачать текущие виджеты в файле JSON. JSON – это текстовый формат данных.
2. Нажмите кнопку **Import Widgets** (импортировать виджеты) в другой игре и выберите этот файл, чтобы получить тот же набор виджетов.

В панели **Chat Settings** после импорта не забудьте нажать кнопку **Save Widgets** – иначе загруженные виджеты не применятся.
