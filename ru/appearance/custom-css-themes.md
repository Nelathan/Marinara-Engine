# Собственные темы оформления на CSS (Theme Library)

В этом руководстве вы узнаете, как полностью изменить внешний вид приложения Marinara Engine собственной темой оформления на CSS. Здесь описано, как создать, импортировать, экспортировать и включить тему. Вы также увидите, какие переменные CSS можно менять и как темы оформления сочетаются с Card CSS.

## Что такое собственная тема оформления

Собственная тема оформления – это блок CSS, который перекрашивает приложение Marinara Engine. CSS (сокращение от Cascading Style Sheets) – это код, задающий цвета, рамки и отступы во всем приложении. Тема оформления умеет менять фон страницы, акцентный цвет, карточки, рамки, текст и многое другое.

Собственные темы оформления хранятся в разделе **Theme Library** (библиотека тем оформления). Они лежат на сервере Marinara, поэтому доступны на каждом устройстве и в каждом браузере, подключенном к тому же серверу. Остальные настройки оформления работают иначе: они остаются на одном устройстве. О настройках, привязанных к устройству, читайте руководство [Настройки оформления](appearance-settings.md).

Активной может быть только одна собственная тема оформления. При этом в библиотеке можно держать сколько угодно тем и переключаться между ними.

## Где найти раздел Theme Library

1. Откройте панель **Settings** (настройки).
2. Перейдите на вкладку **Addons**.
3. Найдите раздел **Theme Library**.

Раздел называется **Theme Library**, а под названием стоит пояснение "Create, import, activate, edit, export, or remove custom CSS themes."

## Создание темы оформления

1. В разделе **Theme Library** нажмите кнопку **Create Theme** (создать тему оформления).
2. Введите название в поле **Theme name**.
3. Напишите или вставьте CSS в большое текстовое поле.
4. Оставьте переключатель **Preview** (предпросмотр) включенным, чтобы видеть изменения в приложении сразу во время набора. Выключите **Preview**, чтобы остановить живой предпросмотр.
5. Нажмите кнопку **Save** (сохранить).

Новая тема оформления начинается с шаблона. В шаблоне перечислены самые ходовые переменные в виде закомментированных примеров: снимите знаки комментария и подставьте свои значения. Совсем новую тему оформления Marinara включает сразу после сохранения. Одновременно появляется подтверждение с названием темы, например: Theme "My Theme" saved and activated.

Чтобы поправить тему оформления позже, найдите ее в списке **Installed Themes**. Нажмите значок с кодом (всплывающая подсказка читается **Edit theme CSS**), внесите правки и нажмите кнопку **Save**. Правка сохраненной темы обновляет ее, но не меняет то, какая тема активна.

## Импорт и экспорт тем оформления

Темы оформления можно передавать файлами. Это удобно, чтобы перенести тему с одного сервера на другой или отдать ее знакомому.

Как импортировать тему оформления:

1. Нажмите кнопку **Import File** (импортировать файл) в разделе **Theme Library**.
2. Выберите файл `.css` или файл `.json`.
3. Прочитайте всплывающее сообщение. Оно сообщает, сколько тем оформления импортировано, сколько пропущено и сколько не удалось прочитать.

Файл `.css` превращается в одну тему оформления, название берется из имени файла. Файл `.json` может содержать одну или несколько тем, и такие файлы бывают двух видов.

Первый вид – файл, экспортированный из приложения Marinara Engine. В нем каждая тема оформления обернута дополнительными полями, которые Marinara добавляет при экспорте. Читать и править их не нужно. Импортируйте файл как есть.

Второй вид – небольшой файл, который вы пишете сами. Для одной темы оформления достаточно вот этого:

```
{ "name": "My Theme", "css": "..." }
```

Импортированные темы оформления попадают на сервер, но сами по себе не включаются. Если на сервере уже есть тема с таким же названием и таким же CSS, она пропускается, а не добавляется во второй раз.

Чтобы экспортировать тему оформления, найдите ее в списке **Installed Themes** и нажмите значок загрузки (всплывающая подсказка читается **Export theme**). Marinara скачивает файл `.json`, который можно импортировать в другом месте.

## Включение темы оформления

В списке **Installed Themes** показаны все темы оформления, а сверху стоит пункт **Default Theme**.

1. Нажмите на название темы оформления, чтобы сделать ее активной. Активную тему отмечает галочка.
2. Нажмите **Default Theme**, чтобы отключить собственное оформление и вернуть встроенный вид приложения Marinara Engine.

Кнопка **Reset Appearance** (сбросить оформление) находится сверху раздела **App Style** в панели **Settings -> Appearance**. Она тоже отключает активную собственную тему оформления.

Чтобы удалить тему оформления окончательно, нажмите значок корзины в ее строке (всплывающая подсказка читается **Remove theme**) и подтвердите действие в окне **Delete Theme**. CSS этой темы удаляется с сервера безвозвратно.

## Справочник по переменным CSS

В редакторе тем оформления есть сворачиваемый блок **CSS Variable Reference**. Раскройте его, чтобы увидеть самые полезные переменные, значения которых можно переопределить. Тема оформления меняет вид приложения, задавая эти переменные в блоке `:root`. В справочнике перечислены такие переменные:

| Переменная | За что отвечает |
| --- | --- |
| `--background` | Фон страницы |
| `--foreground` | Основной текст |
| `--primary` | Акцент и кнопки |
| `--primary-foreground` | Текст на акцентном фоне |
| `--secondary` | Карточки и поля ввода |
| `--card` | Фон карточки |
| `--border` | Рамки |
| `--muted-foreground` | Приглушенный текст |
| `--sidebar` | Фон боковой панели |
| `--sidebar-border` | Рамка боковой панели |
| `--marinara-shell-edge-border` | Левый и правый края оболочки |
| `--destructive` | Ошибки и удаление |
| `--popover` | Фон раскрывающегося списка |
| `--accent` | Подсветка при наведении |

Этот список не ограничивает вас. Тема оформления может задать любую переменную CSS, которую использует Marinara, и добавить собственные стили.

У некоторых визуальных эффектов есть отдельные переменные. Например, тема оформления может запросить пульсацию акцента строкой `--marinara-theme-accent-pulse: enabled`.

CSS собственной темы оформления проходит очистку перед запуском – ради безопасности. Стили, которые подгружают файл с другого сайта, не работают. Чтобы использовать в теме картинку или шрифт, встройте их в виде URI `data:` вместо ссылки в интернет. URI `data:` держит содержимое файла прямо внутри CSS.

## Ограничения размера и названия

Название темы оформления вмещает до 200 символов. Сам CSS вмещает до 256 KiB, причем считаются байты в кодировке UTF-8, а не символы. Тему крупнее этого предела приложение отклоняет при сохранении или импорте.

## Доступ Admin Access при работе по сети

Создание, правка, импорт, включение и удаление темы оформления – защищенные действия. Это важно только тогда, когда приложение Marinara Engine открыто по сети.

Если приложение Marinara Engine открыто на том же компьютере, где работает сервер, через loopback (его же называют localhost), эти действия просто работают. Если приложение открыто с другого устройства – с телефона или с другого компьютера в сети, – серверу сначала нужен секрет администратора.

Как управлять темами оформления по сети:

1. На сервере задайте `ADMIN_SECRET` в файле `.env`.
2. В приложении откройте **Settings -> Advanced -> Admin Access** и введите то же значение.

Без этого изменения тем оформления по сети не проходят. Полную настройку описывают [Настройки сервера: справочник](../CONFIGURATION.md) и руководство [Удаленный доступ: Basic Auth и список разрешенных адресов](../REMOTE_ACCESS.md).

## Как темы оформления работают вместе с Card CSS

В приложении Marinara Engine есть два способа добавить собственный CSS. Это разные функции, и обе могут действовать одновременно.

Собственная тема оформления перекрашивает все приложение. Ей разрешено переопределять основные переменные приложения Marinara Engine, использовать `!important` и `position: fixed`. В этом и смысл темы оформления.

Card CSS устроен иначе. Автор карточки персонажа или персоны встраивает CSS в карточку, а вы включаете его отдельно в каждом чате. Card CSS очищается строже. Он не может переопределять основные переменные приложения, `!important` из него вырезается, а `position: fixed` превращается в `position: absolute`. Он оформляет сообщения чата, а не все приложение. Смотрите [Руководство по оформлению карточек через Card CSS](card-css-theming.md).

Если приложение выглядит неправильно, стоит проверить и активную тему оформления, и Card CSS. Причиной может быть любой из них.
