# Пользовательские эмодзи, стикеры и GIF

В этом руководстве вы узнаете о дополнительных картинках, которые можно добавлять в чат режима Conversation: пользовательских эмодзи, пользовательских стикерах и найденных GIF. Здесь же объясняется, как задать, какие пользовательские эмодзи и стикеры персонаж может использовать в ответах.

Все это работает только в режиме Conversation. В режимах Roleplay и Game Mode доступна обычная панель эмодзи: без пользовательских эмодзи, без стикеров и без поиска GIF.

## Где это найти

В чате режима Conversation посмотрите на строку ввода сообщения. Там есть круглая кнопка со смайликом – **Emoji, GIFs & stickers** (эмодзи, GIF и стикеры). Нажмите ее, чтобы открыть небольшую панель над строкой ввода.

В панели есть такие вкладки:

- **Emoji**: обычная сетка эмодзи и вкладка со звездочкой **Custom emojis** (пользовательские эмодзи) для загруженных картинок.
- **GIFs**: поиск GIF в реальном времени.
- **Stickers**: загруженные стикеры.

Вкладка **Tools** (инструменты) появляется, когда включены другие инструменты ввода. На мобильном устройстве те же вкладки открываются панелью над клавиатурой.

## Пользовательские эмодзи

Пользовательский эмодзи – это небольшая картинка: ее достаточно загрузить один раз и потом использовать в любом чате режима Conversation. В сообщении она записывается коротким кодом – именем эмодзи в двоеточиях, например `:kekw:`.

Пользовательские эмодзи общие для всего профиля. Загрузите их один раз – и они доступны везде.

### Загрузка пользовательского эмодзи

1. Откройте панель **Emoji, GIFs & stickers** и перейдите на вкладку **Emoji**.
2. Нажмите вкладку со звездочкой **Custom emojis**.
3. Нажмите кнопку **Upload** (загрузить) и выберите один или несколько файлов картинок.
4. В окне **Name this emoji** введите имя и нажмите кнопку **Add**.

Новый эмодзи появится в сетке **Custom emojis**.

Имена эмодзи подчиняются строгим правилам. Длина имени – от 1 до 32 символов. Разрешены только строчные буквы, цифры и подчеркивания. Пробелы и заглавные буквы приложение исправляет само: буквы переводит в строчные, а остальные символы заменяет подчеркиваниями.

Картинка пользовательского эмодзи должна быть не больше 256 на 256 пикселей. Приложение проверяет это при загрузке. Имена не должны повторяться среди всех пользовательских эмодзи. Если имя уже занято, появляется ошибка вида `An emoji named ":name:" already exists.`

Как пользовательский эмодзи можно загрузить и анимированный файл GIF. В чате он воспроизводится с анимацией. С вкладкой **GIFs**, о которой сказано ниже, это никак не связано.

### Использование пользовательского эмодзи

Нажмите любую плитку в сетке **Custom emojis**, чтобы вставить ее короткий код в сообщение. Сообщение при этом не отправляется – вставляется только текст. Короткий код можно набрать и вручную, например `:kekw:`. Имя набирайте строчными буквами, точно так, как оно сохранено.

### Переименование, удаление, экспорт и импорт

Нажмите кнопку **Edit** (изменить) сверху вкладки **Custom emojis**, чтобы включить режим редактирования.

В режиме редактирования:

- Нажмите плитку, чтобы открыть окно **Rename emoji**, затем нажмите кнопку **Rename**.
- Нажмите маленький значок корзины на плитке, чтобы удалить этот эмодзи. Окно **Delete emoji** предупреждает: в сообщениях, где он уже использован, вместо картинки появится обычный текст.
- Нажмите кнопку **Export** (экспорт), чтобы скачать все пользовательские эмодзи в файл `marinara-custom-emojis.json`. Картинки лежат внутри этого файла, поэтому он полностью переносимый.
- Нажмите кнопку **Import** (импорт), чтобы загрузить ранее экспортированный файл. При импорте пропускаются эмодзи, которые не проходят проверку имени или размера либо совпадают по имени с уже существующими.

## Пользовательские стикеры

Пользовательский стикер работает как пользовательский эмодзи, но предназначен для картинок побольше. Стикер записывается как `sticker:name:` и всегда отображается большой картинкой отдельным блоком на своей строке.

Откройте вкладку **Stickers** в той же панели. Загрузка, выбор имени, переименование, удаление, экспорт и импорт работают так же, как у эмодзи, с такими отличиями:

- Окно загрузки называется **Name this sticker**.
- Картинка стикера должна быть не больше 512 на 512 пикселей.
- Имена стикеров не должны повторяться среди всех стикеров. При повторе появляется сообщение `A sticker named "sticker:name:" already exists.`
- При экспорте скачивается файл `marinara-custom-stickers.json`.

### Отправка стикера

Нажмите плитку стикера в сетке. Окно **Send sticker** спросит, как его использовать, и предложит два варианта:

- **Send & reply**: сразу отправляет стикер отдельным сообщением и дает персонажу ответить.
- **Add to message**: вставляет текст `sticker:name:` в сообщение, чтобы можно было продолжить писать.

## Поиск GIF (Giphy)

Вкладка **GIFs** ищет в Giphy – большой онлайн-библиотеке GIF. Наберите запрос в поле поиска или посмотрите список популярного. Нажмите GIF, чтобы отправить его в чат.

### Для поиска GIF нужен ключ

Поиску GIF нужен бесплатный ключ API для Giphy. Ключ API – это секретный код, похожий на пароль: он разрешает Marinara Engine обращаться к сервису Giphy от вашего имени. Без ключа вкладка **GIFs** показывает не результаты, а карточку с инструкцией по настройке.

Чтобы настроить поиск GIF:

1. Откройте панель Giphy Developer Dashboard по адресу `https://developers.giphy.com/dashboard/`.
2. Создайте бесплатный ключ API для веб-приложения.
3. Добавьте ключ в файл `.env`. Это файл настроек сервера Marinara.

Добавьте в `.env` строку такого вида:

```
GIPHY_API_KEY=your_key_here
```

После добавления ключа перезапустите Marinara. Подробное описание файла `.env` есть в руководстве по настройке сервера – ссылка ниже.

### Возрастной рейтинг GIF

Результаты поиска приходят с рейтингом Giphy для взрослой аудитории. Он зафиксирован, и в приложении его не изменить. Среди результатов могут быть двусмысленные и откровенные GIF – учитывайте это при поиске. Источника GIF без интернета или только с безопасным содержимым нет.

## Отметка картинки из галереи как эмодзи или стикера

Любую картинку, уже сохраненную в галерее персонажа или галерее персоны, можно отметить как пользовательский эмодзи или стикер. Такая картинка привязана только к этому персонажу или этой персоне. Она работает только в чатах, где они участвуют.

Чтобы отметить картинку из галереи:

1. Откройте редактор **Character Editor** (редактор персонажа) или **Persona Editor** (редактор персоны).
2. Перейдите на вкладку **Gallery** (галерея) и откройте вложенную вкладку **Images**.
3. Наведите курсор на картинку и нажмите маленькую кнопку с тегом в ее левом верхнем углу.
4. Выберите **Make emoji** или **Make sticker**.
5. В окне **Custom Emoji** или **Custom Sticker** введите имя.

На кнопке с тегом появится назначенное имя.

Ограничения по размеру здесь те же. Вариант **Make emoji** допускает не больше 256 на 256 пикселей, а **Make sticker** – не больше 512 на 512. Если картинка слишком большая для выбранного варианта, появляется красное уведомление об ошибке.

Чтобы изменить отметку позже, снова нажмите кнопку с тегом. В меню есть **Rename**, вариант переключения вида **Switch to sticker** и вариант удаления вида **Remove emoji**. Отметка не перемещает и не копирует картинку – она остается и обычной картинкой галереи.

## Панель **Selection preferences**

Marinara может сообщить отвечающему персонажу, какие из пользовательских эмодзи и стикеров он может использовать в ответе. Этим управляет панель **Selection preferences** (настройки подбора).

Чтобы открыть панель, нажмите значок шестеренки **Selection preferences**. Он находится сверху вкладки **Custom emojis** и вкладки **Stickers**. Обе ведут к одной и той же настройке. Настройка сохраняется отдельно для каждого чата, поэтому в разных чатах она может отличаться.

В панели есть строка выбора режима с тремя вариантами:

- **Semantic** (по умолчанию): предлагает эмодзи и стикеры, которые лучше всего подходят к недавним сообщениям. Этот режим использует локальную модель эмбеддингов – небольшую модель ИИ, которая работает на вашем компьютере. Если она недоступна, режим переключается на **Random**.
- **Random**: каждый раз предлагает случайный набор.
- **Tool-call**: подходящие варианты выбирает отдельный запрос к модели. В появившемся раскрывающемся списке нужно выбрать подключение. Если подключение не выбрано или запрос не удался, подбор возвращается к режиму **Semantic**. В групповом чате, где на одном ходу отвечает несколько персонажей, режим **Tool-call** пропускается, и подбор идет через **Semantic**.

Ниже режимов находится настройка **Max offered (each)** (максимум для каждого вида). Она задает, сколько имен пользовательских эмодзи и сколько имен стикеров предлагается персонажу на каждом ходу. По умолчанию – 20. Допустимые значения – от 1 до 100.

## Как выглядят пользовательские эмодзи и стикеры

В чате режима Conversation короткий код вида `:kekw:` отображается небольшой картинкой прямо в строке текста. Если в сообщении нет ничего, кроме коротких кодов эмодзи, картинки отображаются крупнее.

Стикер вида `sticker:wave:` всегда отображается большой картинкой отдельным блоком на своей строке.

Если имя не найдено – например, после удаления этого эмодзи, – в сообщении показывается обычный текст короткого кода, вида `:kekw:`.

## Для реакций доступен только общий набор эмодзи

На сообщение можно поставить реакцию пользовательским эмодзи. Для реакций доступны только основные пользовательские эмодзи – общий набор. Эмодзи из галерей, стикеры и GIF в реакциях недоступны. О реакциях на сообщения рассказано в руководстве по началу работы с режимом Conversation.
