# 로어북 가져오기와 내보내기

이 가이드에서는 로어북을 Marinara Engine으로 가져오는 방법과 파일로 저장하는 방법을 설명합니다. 파일 하나를 가져오는 방법, 여러 개를 한 번에 가져오는 방법, 그리고 두 가지 내보내기 형식을 다룹니다. 로어북은 키워드에 반응하는 메모를 모아 둔 것입니다. 채팅에 해당 단어가 나오면 Marinara가 그 메모를 AI에 보내는 프롬프트에 넣습니다. 다른 롤플레이 도구에서는 같은 기능을 **World Info**라고 부르기도 합니다.

## 가져올 수 있는 파일

Marinara는 두 종류의 로어북 파일을 읽을 수 있고, 어느 쪽인지는 자동으로 판별합니다.

- Marinara에서 내보낸 로어북. 모든 필드와 폴더가 그대로 유지됩니다.
- 다른 도구의 **World Info** 파일. SillyTavern의 World Info 파일과 V2 캐릭터 카드의 "character-book" 형식이 여기에 해당합니다. 다른 도구의 필드는 Marinara가 자기 필드에 맞춰 옮깁니다.

둘 다 평범한 `.json` 파일입니다. 로어북을 가져오는 데는 계정도 API 키도 필요하지 않습니다.

## 로어북 가져오기

로어북 파일 하나를 가져오는 순서입니다.

1. 앱 왼쪽에서 **Lorebooks**(로어북) 패널을 여세요.
2. 위쪽 동작 줄에서 아래쪽 화살표 아이콘을 클릭하세요. 툴팁에 **Import**(가져오기)라고 표시됩니다. 더하기 아이콘(**New**)과 체크 표시 아이콘(**Select**) 사이에 있습니다. 이 버튼 3개는 아이콘만 보이므로, 마우스를 올리면 이름을 확인할 수 있습니다.
3. **Import Lorebook**(로어북 가져오기) 창이 열립니다. **Drop one or more lorebook files here or click to browse**라고 적힌 상자가 보입니다.
4. `.json` 파일을 상자 위로 끌어다 놓거나, 상자를 클릭해서 파일을 고르세요.
5. 결과가 나올 때까지 기다리세요. 파일마다 초록색 체크와 함께 **Imported lorebook**이 표시되거나, 빨간색 표시와 함께 오류 메시지가 나옵니다.
6. **Close**(닫기)를 클릭하세요. 새 로어북이 **Lorebooks** 패널 목록에 나타납니다.

로어북의 생성 날짜는 가져온 시점이 아니라 가져온 파일에 들어 있던 날짜를 그대로 씁니다.

## 로어북 여러 개를 한 번에 가져오기(일괄 가져오기)

**Import Lorebook** 창은 파일을 한 번에 여러 개 받습니다.

1. **Lorebooks** 패널을 열고 아래쪽 화살표 아이콘을 클릭하세요. 툴팁에 **Import**라고 표시됩니다.
2. `.json` 파일 여러 개를 한꺼번에 상자 위로 끌어다 놓거나, 상자를 클릭해서 여러 파일을 선택하세요.
3. Marinara가 파일을 하나씩 차례로 가져오고, 파일마다 결과 줄을 보여 줍니다. 마지막 줄에는 성공한 개수와 실패한 개수가 나옵니다.

한 번에 Marinara 파일과 **World Info** 파일을 섞어서 넣어도 됩니다. Marinara가 파일마다 따로 확인합니다.

## 로어북 내보내기

내보내기를 하면 로어북 하나가 기기에 파일로 저장됩니다. 로어북을 남에게 공유하거나 다른 설치본으로 옮길 때 쓰는 방법입니다.

1. **Lorebooks** 패널에서 로어북을 클릭해 편집기를 여세요.
2. 편집기 헤더에서 내보내기 아이콘을 클릭하세요. 툴팁에 **Export lorebook**(로어북 내보내기)이라고 표시됩니다.
3. **Export Lorebook** 창이 열리고 선택지가 2개 나옵니다. 하나를 고르세요.
   - **Marinara Native**는 Marinara의 폴더와 모든 항목 필드를 그대로 유지합니다. 로어북을 다른 Marinara 설치본으로 하나도 잃지 않고 옮길 때 쓰세요. 파일 이름은 `.marinara.json`으로 끝납니다.
   - **Compatible JSON**은 다른 롤플레이 도구에서 쓸 수 있도록 폴더 없는 **World Info** 파일로 저장합니다. Marinara에만 있는 일부 정보는 빠집니다. 파일 이름은 `.json`으로 끝납니다.
4. 브라우저가 파일을 다운로드합니다.

Marinara에서 다시 쓸 파일이면 **Marinara Native**를, 다른 도구에서 쓸 파일이면 **Compatible JSON**을 고르세요.

## 로어북 여러 개를 한 번에 내보내기(일괄 내보내기)

로어북 여러 개를 zip 파일 하나로 저장할 수 있습니다.

1. **Lorebooks** 패널에서 위쪽 동작 줄의 체크 표시 아이콘을 클릭하세요. 툴팁에 **Select**라고 표시됩니다.
2. 내보낼 로어북마다 체크박스를 켜세요.
3. 아래쪽 선택 막대에서 **Export**(내보내기)를 클릭하세요.
4. 브라우저가 `marinara-lorebooks.zip`이라는 zip 파일 하나를 다운로드합니다.

일괄 내보내기는 항상 **Marinara Native** 형식을 씁니다. 그래서 다시 Marinara로 가져와도 잃는 정보가 없습니다.

## SillyTavern 폴더 통째로 가져오기

위 순서는 이미 가지고 있는 로어북 파일을 가져오는 방법입니다. SillyTavern 설치 폴더에서 로어북을 바로 끌어올 수도 있습니다. 이 방법을 쓰면 캐릭터, 채팅, 프리셋도 함께 가져옵니다. 폴더 가져오기용 설정 마법사가 따로 있습니다. [SillyTavern에서 가져오기](../data/importing-from-sillytavern.md)를 참고하세요.

## 가져온 다음에

가져온 로어북은 키워드 반응 기능으로 바로 작동합니다. 의미로 항목을 찾아 주는 시맨틱 검색을 쓴다면, 가져온 뒤에 벡터를 다시 만들어야 합니다. [로어북 시맨틱 검색](semantic-search.md)을 참고하세요.
