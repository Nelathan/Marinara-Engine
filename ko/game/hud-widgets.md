# Game Mode: HUD 위젯

이 가이드에서는 Marinara Engine의 Game Mode(게임 모드)에서 쓰는 HUD 위젯을 설명합니다. HUD는 heads-up display의 약자로, 게임 화면 좌우 가장자리에 붙는 작은 정보 패널을 말합니다. 위젯의 종류, 게임 시작 전에 거치는 검토 단계, 패널을 옮기고 고정하는 방법, 위젯 배치를 주고받는 방법을 차례로 다룹니다.

## HUD 위젯이란

HUD 위젯은 게임 도중에 필요한 값을 계속 보여 주는 작은 사용자 지정 패널입니다. 체력 막대, 소지금 카운터, 동료의 호감도 같은 것을 표시합니다. 위젯은 게임마다 따로 둘 수 있습니다. Roleplay(롤플레이)의 HUD 트래커와는 별개의 기능입니다. Roleplay 채팅에서 쓰는 트래커 막대는 아래 관련 가이드를 참고하세요.

위젯은 전부 합쳐 최대 4개까지 둘 수 있습니다. 화면 왼쪽과 오른쪽에 몇 개씩 나눌지는 자유입니다.

위젯은 해당 게임에서 **Custom HUD Widgets**(커스텀 HUD 위젯) 옵션을 켰을 때만 나타납니다. 이 옵션은 설정 마법사에서 기본으로 켜져 있습니다. 옵션이 켜져 있으면 AI 게임 마스터(GM)가 세계를 만들면서 시작 위젯도 함께 설계합니다.

## 위젯 8종

위젯 종류는 여덟 가지입니다. GM이 위젯을 만들 때 종류를 알아서 고릅니다. 직접 위젯을 만들 때는 종류를 골라서 지정할 수도 있습니다.

| 위젯 종류 | 표시 내용 |
|---|---|
| **Progress Bar**(진행 막대) | 최댓값 대비 현재 값을 보여 주는 가로 막대입니다. 체력이나 기력에 알맞습니다. |
| **Gauge**(게이지) | 최댓값 대비 현재 값을 보여 주는 반원형 계기판입니다. |
| **Relationship Meter**(관계도 막대) | 단계 표시와 이름이 붙은 막대입니다. NPC의 호감도나 유대감에 알맞습니다. |
| **Counter**(카운터) | 소지금, 경과 일수, 처치 수처럼 큰 숫자 하나를 보여 줍니다. |
| **Stat Block**(스탯 블록) | 이름과 값이 짝을 이루는 작은 표입니다. STR, DEX 같은 능력치나 상태를 나타내는 단어에 알맞습니다. |
| **List**(목록) | 진행 중인 목표처럼 짧은 항목을 글머리 기호로 나열합니다. |
| **Inventory Grid**(인벤토리 격자) | 아이템 칸을 격자로 배열합니다. 분류 탭과 아이템 개수도 넣을 수 있습니다. |
| **Timer**(타이머) | 분과 초로 표시하는 카운트다운 시계입니다. 실시간으로 줄어들게 할 수 있습니다. |

## 세션 시작 전 검토 창

사용자 지정 위젯이 있으면 첫 턴에 들어가기 전에 검토 단계를 거칩니다. **Start Game**(게임 시작)을 누르는 순간 **Review Starting Widgets**(시작 위젯 검토) 창이 열립니다. 여기에 시작 위젯이 전부 나열되므로, 게임에 확정되기 전에 손볼 수 있습니다.

이 창에서 할 수 있는 일은 다음과 같습니다.

- 위젯의 **Edit**(편집)를 눌러 시작 값을 바꾸거나 **Stat Block**의 항목 이름을 고칩니다.
- **Remove**(제거)를 눌러 필요 없는 위젯을 없앱니다.
- **Back**(뒤로)을 눌러 게임을 시작하지 않고 창을 닫습니다.
- **Start Game**을 눌러 보이는 그대로의 위젯으로 게임을 시작합니다.

진행 중인 게임에서 새 세션을 시작할 때도 비슷한 창이 뜹니다. 제목은 **Prepare Next Session Widgets**(다음 세션 위젯 준비)이고, **Start Game** 자리에 **Start Next Session**(다음 세션 시작) 버튼이 있습니다. 창을 닫는 버튼은 **Back** 대신 **Cancel**(취소)입니다.

## 플레이 도중에 위젯 고치기

게임이 진행되는 동안 GM이 이야기 전개에 맞춰 위젯 값을 갱신합니다. GM이 갱신을 빠뜨렸다면 직접 고칠 수 있습니다.

1. 화면 왼쪽이나 오른쪽 가장자리에서 위젯 패널을 찾으세요.
2. 위젯 머리글에 있는 연필 모양 **Edit** 버튼을 클릭하세요.
3. 편집 창에서 값을 바꾸세요. 예를 들어 막대라면 **Current value**(현재 값)와 **Maximum value**(최대값)를 새로 지정합니다.
4. **Save Changes**(변경 사항 저장)를 클릭하세요.

머리글에는 작은 더하기 또는 빼기 표시도 있습니다. 위젯 머리글을 클릭하면 본문이 접히거나 펼쳐집니다.

## 패널 옮기기와 고정하기

위젯 패널은 기본적으로 제자리에 고정되어 있습니다. 패널마다 머리글에 자물쇠 아이콘이 있습니다.

1. 자물쇠 아이콘을 클릭해 고정을 푸세요. 옅은 테두리가 생기면 옮길 수 있는 상태입니다.
2. 패널을 원하는 자리로 끌어다 놓으세요.
3. 자물쇠 아이콘을 다시 클릭해 제자리에 고정하세요.

패널을 원래 자리로 되돌리려면 자물쇠 아이콘을 더블 클릭하거나, 아이콘에 초점이 있는 상태에서 R 키를 누르세요. 각 패널의 위치와 고정 상태는 게임별로 저장됩니다. 배치는 다른 게임으로 이어지지 않습니다.

휴대폰에서는 위젯이 패널 대신 작은 알약 모양으로 표시됩니다. 알약을 탭하면 해당 위젯이 열리고, X를 탭하면 다시 닫힙니다.

## 직접 위젯 만들기

GM에게 맡기지 않고 위젯을 직접 설계할 수도 있습니다. 수동 위젯 편집기는 두 곳에서 열 수 있습니다.

- 게임 설정 마법사: **Custom HUD Widgets**를 켠 다음 **Build Widget Setup**(위젯 설정 빌드) 토글을 켜세요. 토글 아래에 편집기가 나타납니다.
- 진행 중인 게임: **Chat Settings**(채팅 설정)를 열고 **Widgets**(위젯) 섹션을 여세요.

편집기에서 드롭다운으로 위젯 종류를 고르고 **Add**(추가)를 누르세요. 위젯마다 다음 항목을 지정할 수 있습니다.

- **Icon**(아이콘): 머리글에 표시할 짧은 기호나 이모지입니다.
- **Label**(레이블): 위젯 위쪽에 표시할 이름입니다.
- **Type**(타입): 위젯 8종 중 하나입니다.
- **Side**(위치): **Left HUD**(왼쪽 HUD) 또는 **Right HUD**(오른쪽 HUD)입니다.
- **Accent**(강조): 위젯의 색입니다.

그 아래에는 종류별 전용 항목이 있습니다. 막대는 **Value**(값)와 **Max**(최대), 카운터는 **Count**(개수), 인벤토리 격자는 **Slots**(슬롯)와 **Contents**(내용), 타이머는 **Seconds**(초)와 **Running**(실행 중)을 씁니다. 편집기에는 허용된 4개 중 몇 개를 썼는지도 표시됩니다.

**Chat Settings**에서는 **Save Widgets**(위젯 저장)를 눌러 변경 내용을 게임에 적용하고, **Reset**(초기화)을 누르면 저장하지 않은 편집 내용을 되돌립니다.

## 가져오기와 내보내기로 위젯 주고받기

위젯 배치를 파일로 저장해 두었다가 다른 게임에 불러올 수 있습니다. 설정 마법사와 **Chat Settings**의 **Widgets** 섹션 양쪽에 관련 버튼이 있습니다.

1. **Export Widgets**(위젯 내보내기)를 눌러 현재 위젯을 JSON 파일로 다운로드하세요. JSON은 일반 텍스트로 된 데이터 형식입니다.
2. 다른 게임에서 **Import Widgets**(위젯 가져오기)를 누르고 그 파일을 고르면 같은 위젯이 들어옵니다.

**Chat Settings**에서 가져왔다면 **Save Widgets**를 눌러야 불러온 위젯이 적용되니 잊지 마세요.
