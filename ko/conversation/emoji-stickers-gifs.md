# 사용자 지정 이모지, 스티커, GIF

이 가이드에서는 Conversation 모드(대화 모드) 채팅에 더할 수 있는 이미지를 설명합니다. 사용자 지정 이모지, 사용자 지정 스티커, 검색해서 넣는 GIF가 여기에 해당합니다. 캐릭터가 답변에 쓸 수 있는 사용자 지정 이모지와 스티커를 어떻게 정하는지도 함께 다룹니다.

이 기능은 Conversation 모드에서만 동작합니다. Roleplay와 Game Mode에서는 기본 이모지 선택기만 나오고, 사용자 지정 이모지도 스티커도 GIF 검색도 쓸 수 없습니다.

## 이 도구가 있는 곳

Conversation 모드 채팅에서 메시지 입력 막대를 보세요. 웃는 얼굴 아이콘이 그려진 동그란 버튼이 있고 이름은 **Emoji, GIFs & stickers**(이모지, GIF 및 스티커)입니다. 클릭하면 입력 막대 위로 작은 패널이 열립니다.

패널에는 다음 탭이 있습니다.

- **Emoji**(이모지): 표준 이모지 격자와, 업로드한 이미지가 모이는 별표 모양의 **Custom emojis**(사용자 지정 이모지) 탭이 함께 들어 있습니다.
- **GIFs**: GIF를 바로 검색합니다.
- **Stickers**(스티커): 업로드한 스티커가 모입니다.

다른 입력 도구를 켜 두면 **Tools**(도구) 탭도 함께 나타납니다. 모바일에서는 같은 탭들이 키보드 위쪽 시트로 열립니다.

## 사용자 지정 이모지

사용자 지정 이모지는 한 번 업로드해 두고 어느 Conversation 채팅에서나 다시 쓸 수 있는 작은 이미지입니다. 메시지에서는 숏코드로 씁니다. 숏코드란 이모지 이름을 콜론으로 감싼 형태로, `:kekw:` 같은 모양입니다.

사용자 지정 이모지는 프로필 전체에서 공유됩니다. 한 번만 올려 두면 어디서든 쓸 수 있습니다.

### 사용자 지정 이모지 업로드하기

1. **Emoji, GIFs & stickers** 패널을 열고 **Emoji** 탭으로 이동하세요.
2. 별표 모양의 **Custom emojis** 탭을 클릭하세요.
3. **Upload**(업로드)를 클릭하고 이미지 파일을 하나 이상 고르세요.
4. **Name this emoji**(이 이모지 이름 지정) 창에서 이름을 입력하고 **Add**(추가)를 클릭하세요.

새 이모지가 **Custom emojis** 격자에 나타나면 성공입니다.

이모지 이름에는 엄격한 규칙이 있습니다. 길이는 1자에서 32자까지입니다. 쓸 수 있는 문자는 영문 소문자, 숫자, 밑줄뿐입니다. 공백이나 대문자를 입력하면 앱이 알아서 이름을 정리합니다. 예를 들어 대문자는 소문자로 바꾸고, 나머지 문자는 밑줄로 바꿉니다.

사용자 지정 이모지 이미지는 256 x 256 픽셀을 넘을 수 없습니다. 업로드할 때 앱이 크기를 확인합니다. 이름은 전체 사용자 지정 이모지 안에서 겹치면 안 됩니다. 이미 쓰이고 있는 이름을 고르면 `An emoji named ":name:" already exists.` 같은 오류가 나옵니다.

움직이는 GIF 파일도 사용자 지정 이모지로 올릴 수 있습니다. 채팅에서 애니메이션 그대로 재생됩니다. 아래에서 설명하는 **GIFs** 탭과는 별개 기능입니다.

### 사용자 지정 이모지 사용하기

**Custom emojis** 격자에서 타일을 클릭하면 해당 숏코드가 메시지에 들어갑니다. 이때 메시지가 전송되지는 않고 텍스트만 삽입됩니다. `:kekw:`처럼 숏코드를 직접 입력해도 됩니다. 이름은 저장할 때와 똑같이 소문자로 입력하세요.

### 이름 바꾸기, 삭제, 내보내기, 가져오기

**Custom emojis** 탭 위쪽의 **Edit**(편집)를 클릭하면 편집 모드가 켜집니다.

편집 모드에서는 이렇게 조작합니다.

- 타일을 클릭하면 **Rename emoji**(이모지 이름 변경) 창이 열립니다. 이름을 고친 뒤 **Rename**(이름 바꾸기)을 클릭합니다.
- 타일에 붙은 작은 휴지통 배지를 클릭하면 그 이모지가 삭제됩니다. **Delete emoji**(이모지 삭제) 창은 이미 그 이모지를 쓴 메시지에는 대신 일반 텍스트가 표시된다고 알려 줍니다.
- **Export**(내보내기)를 클릭하면 사용자 지정 이모지 전체가 `marinara-custom-emojis.json` 파일로 다운로드됩니다. 이미지까지 파일 안에 들어 있어서 그대로 옮겨 쓸 수 있습니다.
- **Import**(가져오기)를 클릭하면 앞서 내보낸 파일을 불러옵니다. 이름 규칙이나 크기 규칙에 어긋나는 이모지, 기존 이름과 겹치는 이모지는 건너뜁니다.

## 사용자 지정 스티커

사용자 지정 스티커는 사용자 지정 이모지와 원리가 같고, 더 큰 이미지를 다룹니다. 메시지에는 `sticker:name:` 형태로 쓰며, 항상 한 줄을 차지하는 큰 블록 이미지로 표시됩니다.

같은 패널에서 **Stickers** 탭을 여세요. 업로드, 이름 지정, 이름 바꾸기, 삭제, 내보내기, 가져오기는 모두 이모지와 같은 방식입니다. 다른 점은 다음과 같습니다.

- 업로드 창의 제목은 **Name this sticker**(이 스티커 이름 지정)입니다.
- 스티커 이미지는 512 x 512 픽셀을 넘을 수 없습니다.
- 스티커 이름은 전체 스티커 안에서 겹치면 안 됩니다. 이름이 겹치면 `A sticker named "sticker:name:" already exists.`가 표시됩니다.
- 내보내면 `marinara-custom-stickers.json` 파일로 다운로드됩니다.

### 스티커 보내기

격자에서 스티커 타일을 클릭하세요. **Send sticker** 창이 열리면서 어떻게 쓸지 두 가지 중에 고르게 합니다.

- **Send & reply**: 스티커를 바로 하나의 메시지로 올리고 캐릭터가 답하게 합니다.
- **Add to message**: `sticker:name:` 텍스트를 메시지에 넣어 두어 이어서 입력할 수 있게 합니다.

## GIF 검색(Giphy)

**GIFs** 탭은 대규모 온라인 GIF 라이브러리인 Giphy를 검색합니다. 검색창에 입력해서 GIF를 찾거나 인기 목록을 둘러보세요. GIF를 클릭하면 채팅으로 전송됩니다.

### GIF 검색에는 키가 필요합니다

GIF 검색에는 무료 Giphy API 키가 필요합니다. API 키는 Marinara Engine이 대신 Giphy 서비스와 통신하도록 해 주는, 비밀번호 같은 비밀 문자열입니다. 키가 없으면 **GIFs** 탭에는 결과 대신 설정 안내 카드가 표시됩니다.

GIF 검색을 설정하는 방법은 다음과 같습니다.

1. Giphy Developer Dashboard를 `https://developers.giphy.com/dashboard/`에서 여세요.
2. 웹 앱용 무료 API 키를 만드세요.
3. `.env` 파일에 키를 추가하세요. 이 파일은 Marinara의 서버 설정 파일입니다.

`.env`에 다음과 같은 줄을 추가하세요.

```
GIPHY_API_KEY=your_key_here
```

키를 추가했으면 Marinara를 다시 시작하세요. `.env` 파일에 대한 자세한 설명은 아래에 링크한 서버 설정 가이드를 참고하세요.

### GIF 콘텐츠 등급

GIF 검색 결과에는 Giphy의 성인 콘텐츠 등급이 적용됩니다. 이 값은 고정이라 앱에서 바꿀 수 없습니다. 선정적이거나 성인용 GIF가 섞여 나올 수 있으니 감안하고 검색하세요. 오프라인 GIF 소스나 안전한 결과만 주는 소스는 없습니다.

## 갤러리 이미지를 이모지나 스티커로 지정하기

Character Gallery나 Persona Gallery에 이미 저장해 둔 이미지는 어느 것이든 사용자 지정 이모지나 스티커로 지정할 수 있습니다. 이렇게 지정한 갤러리 이미지는 그 캐릭터 또는 페르소나 하나에만 묶입니다. 해당 캐릭터나 페르소나가 들어간 채팅에서만 동작합니다.

갤러리 이미지를 지정하는 방법은 다음과 같습니다.

1. **Character Editor**(캐릭터 편집기)나 **Persona Editor**(페르소나 편집기)를 여세요.
2. **Gallery**(갤러리) 탭으로 이동해 **Images**(이미지) 하위 탭을 여세요.
3. 이미지 위에 마우스를 올리고 왼쪽 위 모서리의 작은 태그 버튼을 클릭하세요.
4. **Make emoji**(이모지로 만들기) 또는 **Make sticker**(스티커로 만들기)를 고르세요.
5. **Custom Emoji** 또는 **Custom Sticker** 창에서 이름을 입력하세요.

태그 버튼에 지정한 이름이 표시되면 성공입니다.

크기 제한은 여기서도 같습니다. **Make emoji**는 256 x 256 픽셀, **Make sticker**는 512 x 512 픽셀까지입니다. 고른 종류에 비해 이미지가 너무 크면 빨간 오류 알림이 뜹니다.

지정한 이미지를 나중에 바꾸려면 태그 버튼을 다시 클릭하세요. 메뉴에는 **Rename**, **Switch to sticker** 같은 전환 항목, **Remove emoji** 같은 해제 항목이 있습니다. 태그를 붙여도 이미지가 옮겨지거나 복사되지는 않습니다. 갤러리의 일반 이미지로도 그대로 남습니다.

## 선택 환경설정

Marinara는 답변할 캐릭터에게 사용자 지정 이모지와 스티커 중 어떤 것을 써도 되는지 알려 줄 수 있습니다. 이 동작은 **Selection preferences**(선택 설정)에서 정합니다.

패널을 열려면 톱니바퀴 아이콘 **Selection preferences**를 클릭하세요. 이 아이콘은 **Custom emojis** 탭과 **Stickers** 탭 위쪽에 있습니다. 어느 쪽으로 열어도 같은 설정입니다. 이 설정은 채팅마다 따로 저장되므로 채팅별로 다르게 둘 수 있습니다.

패널에는 세 가지 중에 고르는 모드 항목이 하나 있습니다.

- **Semantic**(기본값): 최근 대화 흐름에 가장 잘 맞는 이모지와 스티커를 제시합니다. 이 모드는 로컬 임베더를 사용합니다. 임베더는 컴퓨터에서 직접 돌아가는 작은 AI 모델입니다. 쓸 수 없는 상태라면 무작위 방식으로 대체됩니다.
- **Random**: 답변마다 무작위로 골라 제시합니다.
- **Tool-call**: 답변마다 모델을 호출해서 어울리는 것을 고릅니다. 이때 나타나는 드롭다운에서 연결을 골라야 합니다. 연결을 고르지 않았거나 실패하면 **Semantic** 방식으로 대체됩니다. 그룹 채팅에서 한 턴에 캐릭터가 둘 이상 답할 때는 그 턴에 한해 **Tool-call**을 건너뛰고 **Semantic** 방식으로 선택합니다.

모드 아래에는 **Max offered (each)**(각 항목별 최대 제안 수)가 있습니다. 한 턴에 캐릭터에게 제시할 사용자 지정 이모지 이름 수와 스티커 이름 수를 각각 정하는 값입니다. 기본값은 20이고, 1에서 100까지 지정할 수 있습니다.

## 사용자 지정 이모지와 스티커가 표시되는 방식

Conversation 채팅에서 `:kekw:` 같은 이모지 숏코드는 글자 줄 안에 작은 이미지로 표시됩니다. 메시지에 이모지 숏코드만 있고 다른 내용이 없으면 더 크게 표시됩니다.

`sticker:wave:` 같은 스티커는 항상 한 줄을 차지하는 큰 블록 이미지로 표시됩니다.

이름을 찾을 수 없을 때는, 예를 들어 그 이모지를 삭제한 뒤에는 `:kekw:`처럼 숏코드 텍스트가 그대로 표시됩니다.

## 반응에서 쓸 수 있는 이모지

메시지에 사용자 지정 이모지로 반응을 남길 수 있습니다. 반응에 쓸 수 있는 것은 전역으로 공유되는 기본 사용자 지정 이모지뿐입니다. 갤러리에서 지정한 이모지, 스티커, GIF는 반응으로 쓸 수 없습니다. 메시지 반응은 Conversation 모드 시작 가이드에서 다룹니다.
