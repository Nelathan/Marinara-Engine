# Windows इंस्टॉलेशन गाइड

इस गाइड में बताया गया है कि Marinara Engine को Windows पर कैसे इंस्टॉल करें। इसके लिए एक क्लिक वाला इंस्टॉलर है, जो सबसे आसान रास्ता है, और चाहें तो सोर्स से भी सेट कर सकते हैं। साथ में सिस्टम की ज़रूरतें, वैकल्पिक फ़ीचर और बाद में अपडेट करने का तरीका भी शामिल है।

## सिस्टम की ज़रूरतें

Marinara Engine आपके अपने Windows PC पर चलता है। इसके लिए ये चीज़ें चाहिए:

- Windows 10 या Windows 11 (64 बिट)।
- ऐप और उसकी डिपेंडेंसी के लिए कुछ गीगाबाइट खाली डिस्क स्पेस।
- इंस्टॉल के दौरान इंटरनेट कनेक्शन (कोड और पैकेज डाउनलोड करने के लिए)।

दोनों तरीकों में दो टूल चाहिए। इंस्टॉलर इन्हें खुद ला सकता है। सोर्स वाले तरीके में इन्हें खुद इंस्टॉल करना पड़ता है:

- **Node.js** वर्ज़न 24, 25 या 26। Node.js ही ऐप को चलाता है। वर्ज़न 24 सुझाया गया LTS रिलीज़ है। LTS यानी Long Term Support, एक स्थिर वर्ज़न।
- **Git**। Git कोड डाउनलोड करता है और बाद में ऐप को खुद अपडेट होने देता है।

pnpm वह पैकेज मैनेजर है जो ऐप के हिस्से इंस्टॉल करता है। इंस्टॉलर या **start.bat** लॉन्चर इस्तेमाल करें, तो pnpm खुद इंस्टॉल करने की ज़रूरत नहीं। दोनों सही pnpm वर्ज़न Corepack के ज़रिए ले आते हैं, जो Node.js के साथ आने वाला pnpm हेल्पर है, या फिर एक अस्थायी डाउनलोड से। सिर्फ़ लॉन्चर के बिना वाले मैन्युअल सेटअप में `pnpm` कमांड आपके सिस्टम पर होनी ज़रूरी है। उस हिस्से में इंस्टॉल का स्टेप दिया गया है।

## तरीका 1: Windows इंस्टॉलर (सुझाया गया)

शुरुआत का सबसे आसान रास्ता इंस्टॉलर है। यह Node.js और Git की जाँच करता है, न मिलने पर उन्हें इंस्टॉल करने में मदद करता है, ऐप डाउनलोड करता है, उसे बनाता है और शॉर्टकट भी बना देता है।

ये स्टेप अपनाएँ:

1. ब्राउज़र में Marinara Engine का रिलीज़ पेज खोलें।

```text
https://github.com/Pasta-Devs/Marinara-Engine/releases
```

2. उसी पेज से सबसे नई Windows इंस्टॉलर फ़ाइल डाउनलोड करें।
3. इंस्टॉलर चलाएँ और स्क्रीन पर आने वाले निर्देशों का पालन करें। Node.js या Git मौजूद न हों, तो इंस्टॉलर को उन्हें इंस्टॉल करने दें।
4. पूछे जाने पर इंस्टॉल फ़ोल्डर चुनें, या डिफ़ॉल्ट रहने दें।
5. इंस्टॉलर के ऐप डाउनलोड करने और उसे बनाने तक इंतज़ार करें। इसमें कुछ मिनट लग सकते हैं।
6. काम पूरा होने पर डेस्कटॉप पर बने नए शॉर्टकट पर डबल क्लिक करके Marinara Engine खोलें।

थोड़ी देर बाद ब्राउज़र में ऐप खुल जाना चाहिए। अपने आप न खुले, तो ब्राउज़र खोलकर इस पते पर जाएँ:

```text
http://127.0.0.1:7860
```

इंस्टॉलर ऐप की Git वाली कॉपी सेट करता है। यानी अगली बार खोलने पर यह खुद को अपडेट कर सकता है। नीचे अपडेट वाला हिस्सा देखें।

एंटीवायरस इंस्टॉलर को लेकर चेतावनी दे, तो यह पहले से जाना-पहचाना झूठा अलार्म है। इंस्टॉलर Node.js और Git डाउनलोड करता है, और कुछ एंटीवायरस टूल इसी बर्ताव पर निशान लगा देते हैं। इंस्टॉलर तभी चलाएँ जब उसे ऊपर दिए गए आधिकारिक रिलीज़ पेज से डाउनलोड किया हो।

## तरीका 2: सोर्स से इंस्टॉल करना

यह तरीका तब चुनें जब कमांड खुद चलाना पसंद हो, या टेस्टर (staging) वर्ज़न चाहिए हो।

### स्टेप 1: Node.js और Git इंस्टॉल करना

1. आधिकारिक साइट से Node.js इंस्टॉलर डाउनलोड करके चलाएँ।

```text
https://nodejs.org/en/download
```

2. आधिकारिक साइट से Git इंस्टॉलर डाउनलोड करके चलाएँ।

```text
https://git-scm.com/download/win
```

3. नई Command Prompt विंडो खोलें। जाँच लें कि Node.js का वर्ज़न 24, 25 या 26 है:

```bat
node -v
```

4. जाँच लें कि Git इंस्टॉल है:

```bat
git --version
```

हर कमांड पर एक वर्ज़न नंबर दिखना चाहिए। कोई कमांड न मिले, तो Command Prompt बंद करके दोबारा खोलें, या जो टूल छूट गया है उसे फिर से इंस्टॉल करें।

### स्टेप 2: कोड डाउनलोड करना और ऐप चलाना

**start.bat** नाम की लॉन्चर स्क्रिप्ट सेटअप का काम खुद कर देती है। यह सही pnpm वर्ज़न चुनती है, डिपेंडेंसी इंस्टॉल करती है, ऐप बनाती है और ब्राउज़र खोल देती है।

1. Git से कोड डाउनलोड करें:

```bat
git clone https://github.com/Pasta-Devs/Marinara-Engine.git
```

2. नए फ़ोल्डर में जाएँ:

```bat
cd Marinara-Engine
```

3. वैकल्पिक: टेस्टर वर्ज़न पर जाएँ। डाउनलोड स्थिर वर्ज़न से शुरू होता है। इसकी जगह टेस्टर (staging) वर्ज़न चाहिए, तो पहली बार चलाने से पहले यह कमांड चलाएँ। स्थिर वर्ज़न ही चाहिए तो यह स्टेप छोड़ दें। टेस्टर बिल्ड इस्तेमाल करने से पहले अपना डेटा बैकअप कर लें।

```bat
git checkout staging
```

इस बदलाव के बाद लॉन्चर अपडेट करते समय भी आपको टेस्टर वर्ज़न पर ही रखता है।

4. लॉन्चर चलाएँ:

```bat
start.bat
```

पहली बार चलाने में कुछ मिनट लगते हैं, क्योंकि तभी सब कुछ इंस्टॉल और बिल्ड होता है। तैयार होते ही ब्राउज़र में ऐप `http://127.0.0.1:7860` पर खुल जाता है। बाद में ऐप दोबारा शुरू करने के लिए उसी फ़ोल्डर से **start.bat** चलाएँ।

लॉन्चर ऐप को डिफ़ॉल्ट रूप से आपके लोकल नेटवर्क पर खोलता है, इसलिए नेटवर्क के दूसरे डिवाइस भी उस तक पहुँच सकते हैं। नीचे दूसरे डिवाइस से खोलना वाला हिस्सा देखें।

### लॉन्चर के बिना मैन्युअल सेटअप

**start.bat** के बजाय हर कमांड खुद चलानी हो, तो यह सब `Marinara-Engine` फ़ोल्डर के अंदर से करें।

1. pnpm इंस्टॉल करें। इस रास्ते में लॉन्चर इस्तेमाल नहीं होता, इसलिए `pnpm` कमांड आपके सिस्टम पर होनी ज़रूरी है। `npm` कमांड Node.js के साथ ही आती है। यह एक बार चलाएँ:

```bat
npm install -g pnpm
```

2. डिपेंडेंसी इंस्टॉल करें:

```bat
pnpm install --force
```

3. ऐप बनाएँ:

```bat
pnpm build
```

4. सर्वर शुरू करें:

```bat
pnpm start
```

5. ब्राउज़र में ऐप खोलें:

```text
http://127.0.0.1:7860
```

सब कुछ आपके अपने कंप्यूटर पर चलता है। इस मैन्युअल तरीके में ऐप `127.0.0.1` पर सुनता है, यानी उस तक सिर्फ़ यही कंप्यूटर पहुँच सकता है। नेटवर्क के दूसरे डिवाइस को जुड़ने देने के लिए `Marinara-Engine` फ़ोल्डर में `.env` नाम की फ़ाइल बनाएँ। उसमें यह पंक्ति जोड़ें, फिर सर्वर दोबारा शुरू करें:

```env
HOST=0.0.0.0
```

## वैकल्पिक: AI से स्प्राइट का बैकग्राउंड हटाना

Marinara Engine जेनरेट होने वाले स्थिर स्प्राइट के लिए नेटिव ट्रांसपेरेंसी माँगता है, और सादे क्रोमा तथा पुराने सफ़ेद बैकग्राउंड के लिए इसमें अडैप्टिव मैट क्लीनअप पहले से मौजूद है। बारीक नज़ारों और ऐसे बाकी बैकग्राउंड के लिए, जो सादे नहीं हैं, `backgroundremover` नाम का एक वैकल्पिक टूल भी इंस्टॉल किया जा सकता है। यह वैकल्पिक इसलिए है क्योंकि इसमें मशीन लर्निंग की बड़ी फ़ाइलें डाउनलोड होती हैं।

इसके लिए पहले Python चाहिए। आधिकारिक साइट से Python 3.11 इंस्टॉल करें, फिर `Marinara-Engine` फ़ोल्डर से इंस्टॉल कमांड चलाएँ:

```text
https://www.python.org/downloads/windows/
```

इंस्टॉल वाला स्टेप चलाएँ:

```bat
pnpm backgroundremover:install
```

इससे आपके डेटा फ़ोल्डर के नीचे एक निजी Python फ़ोल्डर बन जाता है, जिसे venv कहते हैं। इसके बाद Marinara Engine स्प्राइट क्लीनअप के लिए उसे अपने आप इस्तेमाल करता है। venv यानी अपने आप में पूरा एक Python सेटअप, जिसका बाकी सिस्टम पर कोई असर नहीं पड़ता।

यह टूल अगली बार खोलने पर **start.bat** से भी इंस्टॉल करवाया जा सकता है। अपनी `.env` फ़ाइल में यह पंक्ति जोड़ें:

```env
BACKGROUNDREMOVER_AUTO_INSTALL=true
```

## दूसरे डिवाइस से खोलना

Marinara Engine को उसी नेटवर्क पर मौजूद अपने फ़ोन, टैबलेट या किसी दूसरे कंप्यूटर से भी खोल सकते हैं। सेटअप के स्टेप और सुरक्षा के विकल्प [अक्सर पूछे जाने वाले सवाल](../FAQ.md) गाइड में देखें।

## Marinara Engine अपडेट करना

अपडेट करने पर आपकी चैट, कैरेक्टर और सेटिंग्स जस की तस बनी रहती हैं। Windows पर Marinara Engine अपडेट करने के तीन तरीके देता है।

### लॉन्चर से अपने आप अपडेट

डेस्कटॉप शॉर्टकट या **start.bat** से Git वाली कॉपी खोलने पर लॉन्चर पहले अपडेट की जाँच करता है। नया वर्ज़न मौजूद हो, तो वह बदलाव डाउनलोड करता है, डिपेंडेंसी दोबारा इंस्टॉल करता है, ऐप फिर से बनाता है और तब जाकर उसे शुरू करता है। यह इंस्टॉलर वाले सेटअप और मैन्युअल clone, दोनों पर काम करता है।

एक बार की जाँच छोड़नी हो तो `start.bat --skip-update` चलाएँ। हर बार खोलने पर इंस्टॉल किया गया Engine वर्ज़न बनाए रखने के लिए `.env` में `AUTO_UPDATE_ENABLED=false` जोड़ें। मैन्युअल जाँच, ऐप के अंदर से अपडेट लागू करना और Git से मैन्युअल अपडेट, ये सब फिर भी उपलब्ध रहते हैं।

कोड में आपके कुछ लोकल बदलाव सेव किए बिना पड़े हों, तो लॉन्चर उन्हें सुरक्षित तरीके से अलग रखने की कोशिश करता है। अपडेट के बाद वह उन्हें वापस लगा देता है। ऐसा न हो पाए, तो वह आपका मौजूदा वर्ज़न ही रहने देता है और एक नोट दिखा देता है।

### ऐप के अंदर से अपडेट

अपडेट ऐप के अंदर से भी देखे जा सकते हैं।

1. **Settings** (सेटिंग्स) खोलें।
2. **Advanced** टैब पर जाएँ।
3. **Updates** वाला हिस्सा ढूँढें।
4. **Release Channel** में चैनल चुनें। सामान्य वर्ज़न के लिए **Latest Stable** चुनें, और शुरुआती टेस्टर बिल्ड के लिए **Staging/UAT**। टेस्टर बिल्ड इस्तेमाल करने से पहले अपना डेटा बैकअप कर लें।
5. **Check for Updates** पर क्लिक करें। नया वर्ज़न उपलब्ध हो, तो ऐप बता देता है।

**Apply Update** बटन सुरक्षा के लिए डिफ़ॉल्ट रूप से बंद रहता है। ऐप के अंदर से अपडेट लागू करने के लिए थोड़ा और सेटअप चाहिए। अपनी `.env` फ़ाइल में ये वैल्यू सेट करें:

```env
UPDATES_APPLY_ENABLED=true
ADMIN_SECRET=your-own-secret-value
```

फिर **Settings** खोलें, **Advanced** टैब पर जाएँ, **Admin Access** ढूँढें और वही सीक्रेट वैल्यू वहाँ पेस्ट करें। इसके बाद **Apply Update** बटन इस्तेमाल के लिए उपलब्ध हो जाता है।

ऐप को ऐसे iPhone या iPad से खोलें जो इसी Windows PC से जुड़ा है, तो **Apply Update** इसी Windows सर्वर को अपडेट करता है। किसी रिमोट डिवाइस से अपडेट लागू करने के लिए `.env` में एक और वैल्यू भी चाहिए:

```env
UPDATES_ALLOW_REMOTE_APPLY=true
```

ऐप के अंदर से अपडेट लागू करना चालू न करना हो, तो अपडेट के लिए बस शॉर्टकट या **start.bat** से ऐप दोबारा खोल लें।

### मैन्युअल अपडेट

लॉन्चर के बिना Git वाली कॉपी इस्तेमाल कर रहे हों, तो हाथ से भी अपडेट कर सकते हैं। ये कमांड `Marinara-Engine` फ़ोल्डर से चलाएँ।

1. सबसे नया स्थिर कोड लाएँ:

```bat
git fetch origin +refs/heads/main:refs/remotes/origin/main
```

2. सबसे नए स्थिर वर्ज़न पर जाएँ:

```bat
git merge --ff-only origin/main || git checkout --detach origin/main
```

3. डिपेंडेंसी दोबारा इंस्टॉल करें:

```bat
pnpm install --force
```

4. ऐप फिर से बनाएँ:

```bat
pnpm build
```

5. सर्वर दोबारा शुरू करें:

```bat
pnpm start
```

टेस्टर बिल्ड के लिए इसकी जगह staging ब्रांच इस्तेमाल करें। ऊपर के स्टेप 1 और 2 की जगह ये दो कमांड चलाएँ। फिर इंस्टॉल और बिल्ड वाले स्टेप जारी रखें:

```bat
git fetch origin +refs/heads/staging:refs/remotes/origin/staging
```

```bat
git checkout -B staging origin/staging
```

## कुछ गड़बड़ हो जाए तो

इंस्टॉल या ऐप शुरू होने में गड़बड़ी आए, तो पहले जाँच लें कि Node.js का वर्ज़न 24, 25 या 26 है और Git इंस्टॉल है। एंटीवायरस इंस्टॉलर या डाउनलोड को रोक दे, तो ऊपर बताए मुताबिक यह पहले से जाना-पहचाना झूठा अलार्म है।

और उपाय [Marinara Engine की समस्याएँ सुलझाना](../TROUBLESHOOTING.md) गाइड में देखें।
