# कस्टम CSS थीम (Theme Library)

इस गाइड में बताया गया है कि कस्टम CSS थीम से Marinara Engine का पूरा लुक कैसे बदलें। यहाँ थीम बनाना, इंपोर्ट करना, एक्सपोर्ट करना और चालू करना सीखेंगे। साथ ही यह भी पता चलेगा कि कौन-कौन से CSS वेरिएबल बदले जा सकते हैं और थीम Card CSS के साथ कैसे चलती है।

## कस्टम थीम क्या है

कस्टम थीम यानी CSS का एक हिस्सा जो Marinara को नए रंग-रूप में ढाल देता है। CSS का पूरा नाम Cascading Style Sheets है। यही वह कोड है जो पूरे ऐप में रंग, बॉर्डर और स्पेसिंग तय करता है। थीम से पेज का बैकग्राउंड, एक्सेंट रंग, कार्ड, बॉर्डर, टेक्स्ट और बहुत कुछ बदला जा सकता है।

कस्टम थीम **Theme Library** (थीम लाइब्रेरी) में रहती हैं। Marinara Engine इन्हें आपके सर्वर पर सेव करता है, इसलिए ये उसी सर्वर से जुड़ने वाले हर डिवाइस और ब्राउज़र पर एक जैसी दिखती हैं। बाकी ज़्यादातर अपीयरेंस सेटिंग्स ऐसी नहीं हैं, वे सिर्फ़ एक डिवाइस पर रहती हैं। हर डिवाइस पर अलग रहने वाली सेटिंग्स के लिए [Appearance सेटिंग्स](appearance-settings.md) गाइड देखें।

एक समय पर सिर्फ़ एक कस्टम थीम चालू रह सकती है। लाइब्रेरी में जितनी चाहें उतनी थीम रखें और उनके बीच स्विच करते रहें।

## Theme Library कहाँ मिलती है

1. **Settings** (सेटिंग्स) खोलें।
2. **Addons** टैब खोलें।
3. **Theme Library** सेक्शन ढूँढें।

इस सेक्शन का नाम **Theme Library** है और उसके नीचे लिखा रहता है "Create, import, activate, edit, export, or remove custom CSS themes."

## थीम बनाना

1. **Theme Library** सेक्शन में **Create Theme** पर क्लिक करें।
2. **Theme name** फ़ील्ड में नाम टाइप करें।
3. बड़े टेक्स्ट बॉक्स में अपना CSS लिखें या पेस्ट करें।
4. **Preview** चालू रहने दें, ताकि टाइप करते ही बदलाव ऐप में लाइव दिखें। लाइव प्रीव्यू रोकना हो तो **Preview** बंद कर दें।
5. **Save** पर क्लिक करें।

नई थीम एक टेम्पलेट से शुरू होती है। टेम्पलेट में आम वेरिएबल कमेंट किए हुए उदाहरणों के रूप में दिए रहते हैं, इसलिए कमेंट के निशान हटाकर अपनी वैल्यू भरी जा सकती हैं। बिल्कुल नई थीम सेव करते ही Marinara उसे चालू कर देता है। साथ में थीम के नाम के साथ पुष्टि भी दिखती है, जैसे: Theme "My Theme" saved and activated.

बाद में थीम बदलनी हो तो उसे **Installed Themes** लिस्ट में ढूँढें। कोड आइकन पर क्लिक करें (उसकी टूलटिप में **Edit theme CSS** लिखा रहता है), बदलाव करें और **Save** पर क्लिक करें। सेव की हुई थीम में बदलाव करने से वह अपडेट तो होती है, पर कौन सी थीम चालू है, यह नहीं बदलता।

## थीम इंपोर्ट और एक्सपोर्ट करना

थीम को फ़ाइल के रूप में साझा किया जा सकता है। एक सर्वर से दूसरे सर्वर पर थीम ले जाने या किसी दोस्त को देने में यह काम आता है।

थीम इंपोर्ट करने के लिए:

1. **Theme Library** सेक्शन में **Import File** पर क्लिक करें।
2. कोई `.css` फ़ाइल या `.json` फ़ाइल चुनें।
3. टोस्ट संदेश पढ़ें। उसमें बताया जाता है कि कितनी थीम इंपोर्ट हुईं, कितनी छोड़ी गईं और कितनी फ़ेल हुईं।

`.css` फ़ाइल से एक थीम बनती है, जिसका नाम फ़ाइल के नाम पर रखा जाता है। `.json` फ़ाइल में एक या कई थीम हो सकती हैं, और वह दो तरह की होती है।

पहली तरह वह फ़ाइल है जो Marinara से एक्सपोर्ट हुई हो। एक्सपोर्ट के समय Marinara हर थीम के साथ कुछ अतिरिक्त फ़ील्ड जोड़ देता है। उन्हें पढ़ने या बदलने की ज़रूरत नहीं है। फ़ाइल जैसी है वैसी ही इंपोर्ट करें।

दूसरी तरह वह छोटी फ़ाइल है जो आप खुद लिखें। एक थीम के लिए इतना ही काफ़ी है:

```
{ "name": "My Theme", "css": "..." }
```

इंपोर्ट की हुई थीम सर्वर पर सिंक हो जाती हैं, पर अपने आप चालू नहीं होतीं। अगर सर्वर पर उसी नाम और उसी CSS वाली थीम पहले से मौजूद है, तो उसे दोबारा जोड़ने के बजाय छोड़ दिया जाता है।

थीम एक्सपोर्ट करने के लिए उसे **Installed Themes** लिस्ट में ढूँढें और अपलोड आइकन पर क्लिक करें (उसकी टूलटिप में **Export theme** लिखा रहता है)। Marinara एक `.json` फ़ाइल डाउनलोड करता है, जिसे कहीं और इंपोर्ट किया जा सकता है।

## थीम चालू करना

**Installed Themes** लिस्ट में हर थीम दिखती है, और सबसे ऊपर एक **Default Theme** एंट्री भी रहती है।

1. किसी थीम के नाम पर क्लिक करने से वह चालू हो जाती है। चालू थीम पर सही का निशान दिखता है।
2. कस्टम थीमिंग बंद करके Marinara के अपने लुक पर लौटना हो तो **Default Theme** पर क्लिक करें।

**Reset Appearance** बटन **Settings -> Appearance** में **App Style** सेक्शन के सबसे ऊपर रहता है। इसे दबाने पर चालू कस्टम थीम भी बंद हो जाती है।

थीम को हमेशा के लिए हटाना हो तो उसकी पंक्ति में ट्रैश आइकन पर क्लिक करें (उसकी टूलटिप में **Remove theme** लिखा रहता है), फिर **Delete Theme** विंडो में पुष्टि करें। इससे थीम का CSS सर्वर से पूरी तरह मिट जाता है।

## CSS वेरिएबल रेफ़रेंस

थीम एडिटर में एक **CSS Variable Reference** रहता है, जिसे खोला और बंद किया जा सकता है। उस पर क्लिक करने से सबसे काम के वेरिएबल दिखते हैं, जिन्हें ओवरराइड किया जा सकता है। थीम इन्हीं वेरिएबल को `:root` ब्लॉक में सेट करके ऐप का रूप बदलती है। रेफ़रेंस में ये वेरिएबल दिए हैं:

| वेरिएबल | किस चीज़ पर असर |
| --- | --- |
| `--background` | पेज का बैकग्राउंड |
| `--foreground` | मुख्य टेक्स्ट |
| `--primary` | एक्सेंट और बटन |
| `--primary-foreground` | primary पर आने वाला टेक्स्ट |
| `--secondary` | कार्ड और इनपुट |
| `--card` | कार्ड का बैकग्राउंड |
| `--border` | बॉर्डर |
| `--muted-foreground` | हल्का टेक्स्ट |
| `--sidebar` | साइडबार का बैकग्राउंड |
| `--sidebar-border` | साइडबार का बॉर्डर |
| `--marinara-shell-edge-border` | बाएँ और दाएँ किनारे का बॉर्डर |
| `--destructive` | एरर और डिलीट |
| `--popover` | ड्रॉपडाउन का बैकग्राउंड |
| `--accent` | हॉवर हाइलाइट |

बात सिर्फ़ इसी लिस्ट तक सीमित नहीं है। थीम Marinara का इस्तेमाल किया हुआ कोई भी CSS वेरिएबल सेट कर सकती है, और उसमें दूसरी कस्टम स्टाइल भी जोड़ी जा सकती हैं।

कुछ विज़ुअल इफ़ेक्ट के अपने वेरिएबल हैं। उदाहरण के लिए, `--marinara-theme-accent-pulse: enabled` सेट करके थीम एक्सेंट पल्स एनिमेशन माँग सकती है।

सुरक्षा के लिए कस्टम थीम का CSS चलने से पहले साफ़ किया जाता है। ऐसी स्टाइल काम नहीं करतीं जो किसी दूसरी वेबसाइट से फ़ाइल लोड करती हों। थीम के अंदर कोई इमेज या फ़ॉन्ट इस्तेमाल करना हो तो उसे वेब लिंक के बजाय `data:` URI के रूप में एम्बेड करें। `data:` URI फ़ाइल की सामग्री सीधे CSS के अंदर रखता है।

## साइज़ और नाम की सीमाएँ

थीम का नाम ज़्यादा से ज़्यादा 200 अक्षर लंबा हो सकता है। CSS पेलोड ज़्यादा से ज़्यादा 256 KiB का हो सकता है, जो अक्षरों में नहीं बल्कि UTF-8 बाइट में गिना जाता है। इससे बड़ी थीम सेव या इंपोर्ट करने पर मना कर दी जाती है।

## रिमोट इंस्टॉल के लिए Admin Access

थीम बनाना, बदलना, इंपोर्ट करना, चालू करना और हटाना, ये सब सुरक्षित कार्रवाइयाँ हैं। इसका मतलब सिर्फ़ तब है जब Marinara को नेटवर्क के ज़रिए खोला जाए।

जिस कंप्यूटर पर सर्वर चल रहा है, उसी पर लूपबैक (जिसे localhost भी कहते हैं) से Marinara खोलें तो ये सब सीधे काम करता है। किसी दूसरे डिवाइस से, जैसे फ़ोन या नेटवर्क के किसी दूसरे कंप्यूटर से Marinara खोलें, तो सर्वर को पहले एक एडमिन सीक्रेट चाहिए।

नेटवर्क पर थीम मैनेज करने के लिए:

1. सर्वर पर `.env` फ़ाइल में `ADMIN_SECRET` सेट करें।
2. ऐप में **Settings -> Advanced -> Admin Access** खोलें और वही वैल्यू डालें।

इसके बिना नेटवर्क पर थीम के बदलाव फ़ेल हो जाते हैं। पूरे सेटअप के लिए [सर्वर कॉन्फ़िगरेशन रेफ़रेंस](../CONFIGURATION.md) और [रिमोट एक्सेस: Basic Auth और IP अलाउलिस्ट](../REMOTE_ACCESS.md) देखें।

## थीम और Card CSS साथ में कैसे चलते हैं

Marinara में कस्टम CSS जोड़ने के दो रास्ते हैं। ये अलग-अलग फ़ीचर हैं और दोनों एक साथ चालू रह सकते हैं।

कस्टम थीम पूरे ऐप का रंग-रूप बदलती है। उसे Marinara के कोर वेरिएबल ओवरराइड करने, `!important` लगाने और `position: fixed` इस्तेमाल करने की छूट है। थीम का मकसद ही यही है।

Card CSS इससे अलग है। कैरेक्टर या पर्सोना बनाने वाला व्यक्ति कार्ड के अंदर CSS रख सकता है, और उसे हर चैट में अलग से चालू किया जाता है। Card CSS को ज़्यादा सख्ती से साफ़ किया जाता है। वह ऐप के कोर वेरिएबल ओवरराइड नहीं कर सकता, `!important` हटा दिया जाता है, और `position: fixed` बदलकर `position: absolute` हो जाता है। वह पूरे ऐप को नहीं, सिर्फ़ चैट के संदेशों को स्टाइल करता है। देखें [कार्ड CSS थीमिंग गाइड](card-css-theming.md)।

अगर ऐप का लुक बिगड़ा हुआ लगे तो चालू थीम और Card CSS, दोनों जाँचने लायक हैं। वजह इनमें से कुछ भी हो सकती है।
