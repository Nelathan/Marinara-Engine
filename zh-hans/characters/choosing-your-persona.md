# 在聊天里选择用户角色

本指南介绍怎么挑选在一次聊天里代表自己的用户角色，内容包括全局的当前用户角色、单个聊天的覆盖设置，以及几个快速切换入口。

## 当前用户角色与单聊天用户角色

用户角色就是属于你自己的角色卡，Marinara Engine 用它来代表你。它把你的名字和相关设定告诉 AI，AI 才知道自己在跟谁说话。想了解怎么做一个，见[用户角色](personas.md)。

Marinara 分两层决定用哪个用户角色：

- **当前用户角色**是全局默认值。只要某个聊天没有自己的用户角色，Marinara 就用它。
- 单聊天的用户角色只覆盖那一个聊天，不影响别的。

同一时间只能有一个当前用户角色，也可以一个都不设。

## 设置当前用户角色

按下面的步骤设置全局默认的用户角色。

1. 从右侧边栏打开 **Personas**(用户角色) 面板（人形图标）。
2. 把鼠标移到列表里想用的那个用户角色上。
3. 点击 **Set as active**(设为当前)（该行上的对勾图标）。

当前用户角色的头像上会带一个小对勾标记。设置新的会把旧的标记清掉，所以任何时候都只有一个用户角色处于当前状态。

用 **Active** 和 **Inactive** 两个筛选按钮过滤列表，就能看出哪个是默认。

新建、复制、导入进来的用户角色都不会自动成为当前用户角色，得自己手动设一个。

## 为单个聊天指定用户角色

每个聊天都能存一个自己的用户角色。这就是单聊天的覆盖设置，优先级永远高于当前用户角色。

### 在 Chat Settings 里设置

1. 打开 **Chat Settings**(聊天设置)（聊天旁边的齿轮）。
2. 找到 **Persona** 区域，它的说明文字开头是“Your persona defines who you are in this chat.”
3. 没有设用户角色时，这里显示“No persona selected.”
4. 点击 **Choose Persona**(选择用户角色)。设好之后这个按钮会变成 **Change Persona**。
5. 在选择器里搜索（占位文字是“Search personas...”），点中一个用户角色。

想清掉单聊天的用户角色，点它旁边的移除按钮（X），或者在选择器顶部选 **None**。

在 Game Mode(游戏模式) 里，这一区域会用游戏里队伍的说法来表述，但标签仍然是 **Persona**。

### 新建聊天时

New Chat 设置向导里有一个 **Your Persona** 输入框，用的是同一个可搜索的选择器，同样带 **None** 选项。在 New Game Setup 向导里，这个输入框叫 **Player's Persona**。

## 快速切换用户角色

聊天打开之后，输入框附近会有一个圆形的小头像按钮，这就是 **Quick Persona Switcher**(快速切换用户角色)。没有设用户角色时，它的悬停提示显示的就是这个名字。

1. 点击头像按钮。
2. 弹出一个标题为 **Personas** 的菜单。
3. 点任意一个用户角色即可立刻切换，点 **None** 则不使用用户角色。

用户角色按文件夹分组显示，没有文件夹的归在 **Ungrouped** 下面。

在手机上，用户角色切换和连接切换共用一个菜单。点输入框附近的 **Quick Switcher** 箭头，再打开 **Personas** 选项卡。**Connections**(连接) 选项卡也在同一个菜单里。

## 哪个用户角色说了算

Marinara 按这个顺序决定聊天用哪个用户角色：

1. 聊天自己的单聊天用户角色，前提是设过。
2. 没设的话，用全局的当前用户角色。
3. 两个都没有时，AI 会称呼你为“User”，也不会收到任何用户角色的设定。

在 Game Mode 里，用户角色在 New Game Setup 向导里选一次，之后聊天一直用当时选的那个。也就是说，界面上 Game Mode 的聊天不会跟着当前用户角色变。

聊天中途换用户角色不会改写之前的消息。已经发出去的每条消息，都保留发送时所用的用户角色。
