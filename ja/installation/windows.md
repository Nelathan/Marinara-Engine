# Windowsインストールガイド

このガイドでは、WindowsにMarinara Engineをインストールする手順を説明します。方法は2つあり、ワンクリックインストーラーを使う簡単な方法と、ソースコードから設定する方法があります。動作環境、追加機能、あとからアップデートする方法もあわせて紹介します。

## 動作環境

Marinara Engineは手元のWindowsコンピューターで動きます。必要なものは次のとおりです。

- Windows 10またはWindows 11(64ビット)。
- アプリと関連ファイルを置くための、数ギガバイトの空き容量。
- インストール中のインターネット接続(コードとパッケージのダウンロードに使います)。

どちらの方法でも2つのツールが必要です。インストーラーなら自動で用意してくれます。ソースからの方法では自分でインストールします。

- **Node.js**のバージョン24、25、26のいずれか。Node.jsがアプリを動かします。おすすめはLTS版のバージョン24です。LTSはLong Term Support(長期サポート)の略で、安定版という意味です。
- **Git**。Gitはコードをダウンロードし、あとからアプリが自分自身をアップデートできるようにします。

pnpmは、アプリの構成部品をインストールするパッケージマネージャーです。インストーラーか**start.bat**ランチャーを使う場合、pnpmを自分でインストールする必要はありません。どちらも、Node.jsに同梱されているpnpmの補助ツールCorepackか、一時的なダウンロードを通じて、適切なバージョンのpnpmを取得します。`pnpm`コマンドがコンピューターに入っている必要があるのは、ランチャーを使わない手動セットアップだけです。その節にインストール手順を載せています。

## 方法1: Windowsインストーラー(おすすめ)

いちばん手軽なのがインストーラーです。Node.jsとGitの有無を確認し、なければインストールを手伝い、アプリをダウンロードしてビルドし、ショートカットまで作成します。

手順は次のとおりです。

1. ブラウザーでMarinara Engineのリリースページを開きます。

```text
https://github.com/Pasta-Devs/Marinara-Engine/releases
```

2. そのページから、最新のWindowsインストーラーのファイルをダウンロードします。
3. インストーラーを実行し、画面の指示に従って進めます。Node.jsやGitが見つからない場合は、インストーラーにインストールさせます。
4. インストール先のフォルダーを聞かれたら選ぶか、デフォルトのまま進めます。
5. インストーラーがアプリをダウンロードしてビルドするのを待ちます。数分かかることがあります。
6. 完了したら、デスクトップに追加されたショートカットをダブルクリックしてMarinara Engineを起動します。

少し待つとブラウザーが開いてアプリが表示されます。自動で開かないときは、ブラウザーを開いて次のアドレスにアクセスします。

```text
http://127.0.0.1:7860
```

インストーラーはGitベースのコピーとしてアプリを用意します。そのため、次回の起動時にアプリが自分自身をアップデートできます。詳しくは下のアップデートの節を参照してください。

ウイルス対策ソフトがインストーラーについて警告を出すことがありますが、これは既知の誤検知です。インストーラーがNode.jsとGitをダウンロードする動作を、警告の対象にするソフトがあるためです。インストーラーは、上でリンクした公式のリリースページからダウンロードしたものだけを実行してください。

## 方法2: ソースからインストール

コマンドを自分で実行したい場合や、テスター版(staging)を使いたい場合はこの方法を選びます。

### 手順1: Node.jsとGitをインストールする

1. 公式サイトからNode.jsのインストーラーをダウンロードして実行します。

```text
https://nodejs.org/en/download
```

2. 公式サイトからGitのインストーラーをダウンロードして実行します。

```text
https://git-scm.com/download/win
```

3. 新しいコマンドプロンプトのウィンドウを開きます。Node.jsがバージョン24、25、26のいずれかになっているか確かめます。

```bat
node -v
```

4. Gitが入っているか確かめます。

```bat
git --version
```

どちらのコマンドでもバージョン番号が表示されます。コマンドが見つからないと言われたら、コマンドプロンプトを閉じて開き直すか、足りないツールを入れ直してください。

### 手順2: コードをダウンロードして起動する

**start.bat**というランチャースクリプトがセットアップを代行します。適切なバージョンのpnpmを選び、依存関係をインストールし、アプリをビルドして、ブラウザーを開きます。

1. Gitでコードをダウンロードします。

```bat
git clone https://github.com/Pasta-Devs/Marinara-Engine.git
```

2. 作成されたフォルダーに移動します。

```bat
cd Marinara-Engine
```

3. 任意: テスター版に切り替えます。ダウンロードした直後は安定版です。テスター版(staging)を使いたいときは、最初の起動前に次のコマンドを実行します。安定版を使う場合はこの手順を飛ばしてください。テスター版を使う前にはデータをバックアップしてください。

```bat
git checkout staging
```

一度切り替えると、以降のアップデートでもランチャーはテスター版のまま維持します。

4. ランチャーを実行します。

```bat
start.bat
```

初回の起動は、インストールとビルドをまとめて行うため数分かかります。準備ができるとブラウザーが開き、`http://127.0.0.1:7860`でアプリが表示されます。次回以降は、同じフォルダーで**start.bat**を実行すれば起動できます。

ランチャーはデフォルトでアプリをローカルネットワークに公開するので、同じネットワークにある別のデバイスからもアクセスできます。下の「別のデバイスからアクセスする」を参照してください。

### ランチャーを使わない手動セットアップ

**start.bat**ではなく1つずつコマンドを実行したい場合は、`Marinara-Engine`フォルダーの中で次の操作を行います。

1. pnpmをインストールします。この方法ではランチャーを使わないため、`pnpm`コマンドがコンピューターに入っている必要があります。`npm`コマンドはNode.jsに付属しています。次のコマンドを一度だけ実行します。

```bat
npm install -g pnpm
```

2. 依存関係をインストールします。

```bat
pnpm install --force
```

3. アプリをビルドします。

```bat
pnpm build
```

4. サーバーを起動します。

```bat
pnpm start
```

5. ブラウザーでアプリを開きます。

```text
http://127.0.0.1:7860
```

すべての処理は手元のコンピューターで動きます。この手動の方法ではアプリが`127.0.0.1`で待ち受けます。つまり、このコンピューターからしかアクセスできません。同じネットワークの別のデバイスから接続できるようにするには、`Marinara-Engine`フォルダーに`.env`という名前のファイルを作ります。次の行を書き加えてから、サーバーを再起動します。

```env
HOST=0.0.0.0
```

## 任意: AIによるスプライトの背景除去

Marinara Engineは、生成する静止スプライトにネイティブの透過を要求します。単色の背景や以前の白背景に対しては、適応的なマット処理を内蔵しています。さらに、細かい風景など単色ではない背景に備えて、`backgroundremover`という追加のツールを入れることもできます。大きな機械学習ファイルをダウンロードするため、任意の扱いです。

使うにはまずPythonが必要です。公式サイトからPython 3.11をインストールし、`Marinara-Engine`フォルダーでインストール用のコマンドを実行します。

```text
https://www.python.org/downloads/windows/
```

インストールの手順を実行します。

```bat
pnpm backgroundremover:install
```

これでデータフォルダーの下に専用のPythonフォルダー(venv)ができます。以降、Marinara Engineがスプライトの背景処理に自動で使います。venvとは、システム全体に影響しない独立したPython環境のことです。

次回の起動時に**start.bat**へインストールを任せることもできます。`.env`ファイルに次の行を追加します。

```env
BACKGROUNDREMOVER_AUTO_INSTALL=true
```

## 別のデバイスからアクセスする

同じネットワークにあるスマートフォン、タブレット、別のコンピューターからもMarinara Engineを開けます。設定の手順とセキュリティの選択肢については、[よくある質問](../FAQ.md)のガイドを参照してください。

## Marinara Engineのアップデート

アップデートしても、チャット、キャラクター、設定はそのまま残ります。Windowsでのアップデート方法は3つあります。

### ランチャーによる自動アップデート

Gitベースのコピーで、デスクトップのショートカットまたは**start.bat**からアプリを起動すると、ランチャーが最初にアップデートを確認します。新しいバージョンがあれば、変更をダウンロードし、依存関係を入れ直し、アプリをビルドし直してから起動します。インストーラーで用意した環境でも、手動でクローンした環境でも同じように動きます。

1回だけ確認を飛ばしたいときは`start.bat --skip-update`を実行します。起動のたびに現在のEngineのバージョンを保ちたい場合は、`.env`に`AUTO_UPDATE_ENABLED=false`を追加します。手動での確認、アプリ内からの適用、Gitによる手動アップデートはそのまま使えます。

コードにローカルの未保存の変更があるときは、ランチャーが安全に退避しようとします。アップデート後には元に戻します。退避できない場合は、現在のバージョンのままにして、その旨を表示します。

### アプリ内でのアップデート

アプリの中からアップデートを確認することもできます。

1. **Settings**(設定)を開きます。
2. **Advanced**(詳細設定)タブに移動します。
3. **Updates**(アップデート)の項目を探します。
4. **Release Channel**(リリースチャンネル)でチャンネルを選びます。通常のバージョンなら**Latest Stable**、早期のテスター版なら**Staging/UAT**を選びます。テスター版を使う前にはデータをバックアップしてください。
5. **Check for Updates**(アップデートの確認)をクリックします。新しいバージョンがあるかどうかをアプリが知らせます。

**Apply Update**(アップデートの適用)ボタンは、安全のためデフォルトでオフになっています。アプリの中からアップデートを適用するには、追加の設定が必要です。`.env`ファイルに次の値を設定します。

```env
UPDATES_APPLY_ENABLED=true
ADMIN_SECRET=your-own-secret-value
```

そのうえで**Settings**を開き、**Advanced**タブの**Admin Access**(管理者アクセス)を探して、同じ秘密の値を貼り付けます。これで**Apply Update**ボタンが使えるようになります。

このWindowsコンピューターに接続したiPhoneやiPadからアプリを開いている場合、**Apply Update**はこのWindowsのサーバーをアップデートします。リモートからの適用には、`.env`にもう1つ値が必要です。

```env
UPDATES_ALLOW_REMOTE_APPLY=true
```

アプリ内からの適用を有効にしない場合は、ショートカットか**start.bat**でアプリを起動し直せばアップデートできます。

### 手動でのアップデート

ランチャーを使わずにGitのコピーを使っている場合は、手作業でアップデートできます。次のコマンドは`Marinara-Engine`フォルダーで実行します。

1. 最新の安定版のコードを取得します。

```bat
git fetch origin +refs/heads/main:refs/remotes/origin/main
```

2. 最新の安定版に移動します。

```bat
git merge --ff-only origin/main || git checkout --detach origin/main
```

3. 依存関係を入れ直します。

```bat
pnpm install --force
```

4. アプリをビルドし直します。

```bat
pnpm build
```

5. サーバーを起動し直します。

```bat
pnpm start
```

テスター版の場合はstagingブランチを使います。上の手順1と2の代わりに次の2つのコマンドを実行し、そのあとはインストールとビルドの手順を続けます。

```bat
git fetch origin +refs/heads/staging:refs/remotes/origin/staging
```

```bat
git checkout -B staging origin/staging
```

## うまくいかないときは

インストールや起動に失敗したときは、まずNode.jsがバージョン24、25、26のいずれかであること、そしてGitが入っていることを確かめます。ウイルス対策ソフトがインストーラーやダウンロードをブロックする場合は、上で触れたとおり既知の誤検知です。

ほかの対処法については、[Marinara Engineのトラブルシューティング](../TROUBLESHOOTING.md)のガイドを参照してください。
