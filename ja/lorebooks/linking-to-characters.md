# ロアブックをキャラクターやペルソナに結び付ける

このガイドでは、ロアブックをキャラクターやペルソナに結び付けて、必要なチャットで自動的に有効になるようにする方法を説明します。ロアブックをキャラクターカードの中に埋め込む方法と、チャットごとの**Lorebooks**(ロアブック)の操作についても取り上げます。ロアブックとは、キーワードで発動する世界の設定情報のエントリーをまとめたものです。はじめて触れる場合は[ロアブックの概要](overview.md)を参照してください。

## ロアブックを結び付ける2つの方法

キャラクターにロアブックを結び付ける方法は2つあり、動作が異なります。目的に合うほうを選んでください。

- **リンク(割り当て)**: ロアブックはライブラリーに残ったままで、キャラクターやペルソナがそれを参照します。そのキャラクターが参加しているチャット、またはそのペルソナを使っているチャットで、ロアブックが自動的に有効になります。リンクしたロアブックは、エクスポートしたキャラクターカードには含まれません。
- **埋め込み**: ロアブックをキャラクターカードそのものに書き込みます。キャラクターをエクスポートしたり共有したりすると、カードと一緒に持ち運ばれます。埋め込みができるのはキャラクターだけで、ペルソナにはできません。

ふだんはリンクで十分です。埋め込みは、ロアブックを組み込んだ状態でキャラクターカードを共有したいときにだけ使ってください。

## エディターのLorebookタブ

CharacterエディターにもPersonaエディターにも**Lorebook**タブがあります。

1. キャラクターまたはペルソナを開いて編集状態にします。
2. **Lorebook**タブをクリックします。
3. **New**(新規作成)と**Assign Lorebook**(ロアブックの割り当て)の2つのボタンがある**Lorebooks**セクションが表示されます。

**New**は新しいロアブックを作り、編集中のキャラクターまたはペルソナに最初からリンクした状態にします。**Create Lorebook**(ロアブックの作成)ウィンドウが開き、**Category**(カテゴリー)は**Character**に設定されています。

**Assign Lorebook**は、ライブラリーにある既存のロアブックをリンクします。選択画面に出てくるのは**Character**カテゴリーのロアブックだけです。詳しくは次の項で説明します。

## 既存のロアブックを割り当てる

**Assign Lorebook**の選択画面には、**Category**が**Character**のロアブックしか表示されません。ペルソナを編集しているときも同じです。WorldやNPCなど別のカテゴリーのロアブックは、選択画面にも割り当て済みの一覧にも現れません。表示させるには、そのロアブックを開き、**Overview**(概要)タブで**Category**を**Character**に変更します。**New**ボタンならこの手間がかかりません。Characterカテゴリーのロアブックが自動的に作られるからです。

1. **Lorebook**タブで**Assign Lorebook**をクリックします。
2. 検索欄にロアブック名の一部を入力して探します。
3. 使いたいロアブックをクリックします。横にチェックマークが付きます。
4. 右側で**Scope**(適用範囲)を選びます(次の項を参照)。
5. **Assign**(割り当て)をクリックします。

これでロアブックが割り当て済みの一覧に並びます。各行には、後から範囲を変更する**Scope**ボタンと、リンクを解除するゴミ箱アイコンがあります。ロアブック名をクリックすると、フル機能のエディターで開きます。

Globalに設定したロアブックはすべてのチャットで有効になるため、キャラクターやペルソナにリンクすることはできません。Globalについては[ロアブックの概要](overview.md)で説明しています。

## Scope: リンクしたロアブックを使えるチャットの範囲

**Scope**は、リンクしたロアブックがどこで有効になってよいかを決めます。Marinaraのすべてのチャットという意味ではありません。対象になるのは、このキャラクターが参加しているチャットと、このペルソナを使っているチャットです。範囲は3種類あります。

- **All chats with [name]**: デフォルトです。このキャラクターが参加している、またはこのペルソナを使っているすべてのチャットでロアブックが有効になります。
- **Disabled for all chats**: リンクは残りますが、ロアブックは有効になりません。リンクを解除せずに一時的に止めたいときに使います。
- **Specific chats**: 一覧から対象のチャットを個別に選びます。チェックを入れたチャットだけがロアブックを使えます。一覧に並ぶのは、このキャラクターが参加している、またはこのペルソナを使っているチャットです。

**Specific chats**を選んだ場合は、保存する前にチャットを1つ以上チェックする必要があります。

範囲を後から変えるには、割り当て済みの行にある**Scope**ボタンをクリックし、設定を直してから、もう一度**Assign**をクリックします。

## ロアブックをキャラクターカードに埋め込む

埋め込みは、ロアブックをキャラクターカードに書き込み、キャラクターと一緒にエクスポートされるようにする機能です。使えるのはキャラクターだけです。世界の設定情報を持ったままキャラクターを共有したいときに使ってください。

1. Characterエディターでキャラクターを開きます。
2. **Lorebook**タブに移動します。
3. 対象のロアブックが割り当て済みになっているか確かめます(前の項を参照)。
4. そのロアブックの行で**Embed into card**(カードに埋め込む)をクリックします。

行に**Embedded**バッジが表示されます。これ以降、ロアブックのエントリーはカードの中に置かれ、カードと一緒にエクスポートされます。

キャラクターカードが持てる埋め込みロアブックは、同時に1つだけです。すでに1つある場合、**Embed into card**ボタンは無効になり、「Remove the current embedded lorebook first」という注意書きが出ます。別のロアブックを埋め込む前に、いまの埋め込みを削除してください。

埋め込んだ後にリンク元のロアブックを編集したときは、その行の**Refresh**(更新)をクリックします。ロアブックの現在のエントリーから埋め込みが書き直され、カードの中身が最新の状態になります。

## 埋め込んだロアブックの管理

キャラクターカードに埋め込みロアブックがあると、割り当て済みの一覧の下に追加の操作が現れます。埋め込まれているエントリーの一覧も、読み取り専用で表示されます。

- **Import Embedded Lorebook**: カードに組み込まれたエントリーを、ライブラリーの中の編集できる通常のロアブックに変換します。新しくできたロアブックは、そのキャラクターにリンクされます。リンク済みのものがすでにある場合、ボタンの表示は**Reimport Embedded Lorebook**になります。
- **Edit Embedded Lorebook**: リンクされているロアブックをフル機能のエディターで開きます。ここでの編集は、カードの埋め込みにも自動で反映されます。
- **Remove from card**: カードから埋め込みを削除します。ライブラリーで別にリンクしているロアブックはそのまま残ります。

この機能は、ほかのツールからインポートしたカードで役に立ちます。インポートしたカードには埋め込みロアブックが付いていることが多く、**Import Embedded Lorebook**をクリックすれば、Marinaraで自由に編集できる形にできます。

## Chat SettingsのLorebooksセクション

チャットにはそれぞれ専用の**Lorebooks**の操作があります。ここでは、現在のチャットで有効になっているロアブックを確認し、そのチャットだけを対象に調整できます。

1. チャットを開きます。
2. **Chat Settings**(チャット設定)を開きます。
3. **Lorebooks**セクションを探します。数字のバッジに、有効なロアブックの数が表示されます。

有効なロアブックには、有効になっている理由を示すバッジが1つ以上付きます。

- **Chat**: このチャットに手動でピン留めしました。
- **Global**: Globalに設定したロアブックです。
- **Character**: このチャットのキャラクターにリンクされています。
- **Persona**: このチャットのペルソナにリンクされています。

有効なロアブックは、このチャットだけを対象に変更できます。

- **Add Lorebook**: ロアブックをこのチャットにピン留めします。ピン留めしたロアブックには**Chat**バッジが付きます。
- ゴミ箱アイコン(**Remove from chat**): 手動で追加したロアブックのピン留めを外します。
- 目を閉じたアイコン(**Disable in this chat**): 自動で有効になったロアブックを、リンクを解除せずにこのチャットでだけ一時的に隠します。無効にしたロアブックは、名前に取り消し線が引かれ、**Disabled**バッジが付きます。
- 目のアイコン(**Enable in this chat**): 無効にしたロアブックを、このチャットで再び有効にします。

### Lorebook Token Budget

**Lorebook Token Budget**は、このセクションにある数値の欄です。このチャットで挿入できるロアブックの文章量の上限を、トークン単位で決めます。デフォルトは**8192**です。**0**にすると上限なしになります。このチャット全体の上限は、ロアブックごとのトークン予算とは別のもので、どちらの上限も同時に働きます。2つの予算がどう組み合わさるかは、[ロアブックのトークン予算と再帰](token-budgets.md)を参照してください。
