# 接続の整理

このガイドでは、Marinara Engineに保存した接続をきれいに整理する方法を説明します。接続フォルダー、検索と並べ替え、複製と削除、ランダムプール、Quick Connection Switcher、接続のエクスポートとインポートを取り上げます。接続とは、1つのAIサービスへの接続方法をMarinaraに伝えるための設定をまとめて保存したものです。

ここで説明する操作は、すべて**Connections**(接続)パネルで行います。パネルを開くと、保存済みの接続が行のリストとして並びます。各行には接続の名前が表示され、その下にプロバイダーとモデルが表示されます。

## 接続フォルダー

関連する接続をまとめるには、接続フォルダーを使います。たとえば、ローカルモデルの接続を1つのフォルダーに、有料のプロバイダーの接続を別のフォルダーにまとめられます。

フォルダーを作る手順は次のとおりです。

1. 接続リストの上にある**New Folder**(新規フォルダー)ボタンをクリックします。
2. 「unnamed」という名前のフォルダーが新しく追加されます。
3. 見分けが付くように、すぐに名前を変更します(下記を参照)。

フォルダーの名前を変更するには、フォルダーの行をダブルクリックします。タッチ画面ではダブルタップします。フォルダーの行を選んで**F2**キーを押す方法もあります。新しい名前を入力し、Enterを押します。

接続をフォルダーに入れるには、接続の行をドラッグしてフォルダーの上でドロップします。フォルダーから出すときは、フォルダーより下の領域にドラッグします。ドラッグ中は**Drop here to move out of folder**というヒントが表示されます。

フォルダーを折りたたむ、または展開するには、フォルダーの行を1回クリックします。フォルダーの行にある小さな数字は、中に入っている接続の数を表します。

フォルダーを削除するには、フォルダーの行にあるゴミ箱アイコンをクリックします。中にまだ接続が残っている場合は、Marinaraが**Delete Folder**(フォルダーの削除)ウィンドウで確認します。空のフォルダーは確認なしですぐに削除します。フォルダーを削除しても、中の接続は消えません。それらの接続は、フォルダーに入れていない領域に戻ります。

## 検索と並べ替え

**Search connections**(接続の検索)欄に文字を入力すると、その場でリストが絞り込まれます。検索の対象は、接続の名前、プロバイダー、モデル、ベースURL、画像または動画のサービス、埋め込みモデルです。一致するものがないときは「No connections match your search」と表示します。

検索欄の隣にある**Sort order**(並び順)ドロップダウンで、リストの並び順を変えられます。選べるのは次の5つです。

| 選択肢 | 動作 |
|---|---|
| **Custom** | ドラッグアンドドロップで自分が決めた並び順にします。 |
| **A-Z** | 名前をAからZの順に並べます。 |
| **Z-A** | 名前をZからAの順に並べます。 |
| **Newest** | 新しい接続を先に表示します。 |
| **Oldest** | 古い接続を先に表示します。 |

並び順を自分で決めるには、接続の行を上下にドラッグします。接続をドラッグすると、並び順は自動的に**Custom**に切り替わります。

## 複製と削除

操作ボタンは、接続の行にマウスポインターを重ねると表示されます。タッチ画面では行を見ればそのまま確認できます。

接続を複製するには、**Duplicate**(複製)ボタン(コピーアイコン)をクリックします。保存済みのAPIキーも含めて、そのまま丸ごとコピーします。コピーはエディターで開くので、すぐに名前を変更できます。確認の手順はありません。

接続を1つだけ削除するには、その行の**Delete**(削除)ボタン(ゴミ箱アイコン)をクリックします。Marinaraは**Delete Connection**(接続の削除)ウィンドウを表示し、「Delete "your connection name"? This cannot be undone.」と確認します。**Delete**をクリックすると削除します。

複数の接続をまとめて削除またはエクスポートするには、パネル上部の**Select**(選択)ボタンをクリックします。これで選択モードがオンになります。対象の接続をタップし、画面下部のアクションバーにある**Export**(エクスポート)ボタンまたは**Delete**ボタンを使います。まとめて削除するときは、実際に削除する前に**Delete Connections**ウィンドウが表示されます。

## ランダムプールとQuick Connection Switcher

ランダムプールを使うと、チャットが返信を生成するたびに別の接続を選べます。複数のプロバイダーやモデルにリクエストを分散したいときに便利です。

接続をランダムプールに追加するには、その行のシャッフルアイコンをクリックします。ツールチップには**Add to random pool**と表示されます。プールに入ると、ツールチップは**In random pool (click to remove)**に変わります。もう一度アイコンをクリックすると、その接続をプールから外します。

チャットでランダムプールを使うには、**Chat Settings**(チャット設定)を開き、**Connection**セクションのドロップダウンから**🎲 Random**を選びます。Game Modeでは、このドロップダウンの名前が**GM / Party Model**になります。以降は返信ごとに、プールからランダムに接続を選びます。

**Quick Connection Switcher**(接続の切り替えメニュー)を使うと、開いているチャットの接続をもっと手早く変更できます。チャットの入力欄にあるリンクアイコンをクリックすると開きます。接続の一覧が小さなメニューに表示されます。

- 接続をクリックすると、そのままいま開いているチャットでその接続を使います。
- メニュー上部のダイスボタンをクリックすると、このチャットのランダムプールをオンまたはオフにします。
- ランダムプールがオンのあいだは、接続をクリックする操作がプールへの追加と削除に変わります。プールに入っている接続にはチェックマークが付きます。

## 接続のエクスポートとインポート

接続はファイルにエクスポートできます。バックアップとして保管したり、別のインストール先へ移したりして、あとからインポートできます。

**エクスポートしたファイルにAPIキーは一切含まれません。** 接続をインポートしたあとは、1つずつ開いてAPIキーを入力し直す必要があります。

接続を1つだけエクスポートするには、エディターで開いて**Export**ボタン(アップロードアイコン)をクリックします。まとめてエクスポートするときは、パネルで**Select**モードを使い、アクションバーの**Export**をクリックします。ダウンロードが始まる前に、Marinaraは**Export Connection Data**(接続データのエクスポート)ウィンドウで、This will export your connection data, WITHOUT your provided API Key. Remember to never share those with others!という警告を表示します。そのまま**Export**をクリックすると続行します。

接続が1つのときは`.connection.json`ファイルとしてダウンロードします。複数のときは`marinara-connections.zip`ファイルにまとめてダウンロードします。

接続をインポートするには、**Connections**パネル上部の**Import**(インポート)ボタンをクリックします。**Import Connections**(接続のインポート)ウィンドウが開きます。`.json`ファイルを1つ以上ドロップするか、クリックしてファイルを選びます。ウィンドウにはImported connections never include API keys. Add each key again after import.という注意書きが出ます。インポート直後の接続はAPIキーが空のままなので、あとから入力します。
