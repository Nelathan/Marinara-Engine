# SillyTavernからのインポート

このガイドでは、SillyTavernのデータをMarinara Engineに取り込む方法を説明します。ファイルを1つずつインポートすることも、SillyTavernのフォルダー全体をスキャンしてまとめて取り込むこともできます。

## 引き継げるもの

Marinara Engineがインポートできるのは、次の種類のSillyTavernデータです。

- キャラクター(キャラクターカード)
- チャット(メッセージの記録)
- グループチャット(複数のキャラクターが参加するチャット)
- プリセット(生成設定)
- ロアブック(SillyTavernでは「World Info」と呼ばれます)
- 背景(チャットの背景画像)
- ペルソナ(自分用の**{{user}}**プロフィール)

ロアブックとは、チャットに特定の言葉が出てきたときにAIが読み込むメモをまとめたものです。プリセットは、生成設定をひとまとめにして保存したものです。ペルソナは、チャットの中で自分の代わりになるプロフィールです。

インポートの方法は2つあります。1つのファイルだけを取り込むときは単一ファイル用のボタンを、SillyTavernのインストール内容をまるごと移すときは**Import from SillyTavern Folder**(SillyTavernフォルダーからインポート)のウィザードを使います。

## 単一ファイルの簡易インポート

**Settings**(設定)を開き、**Imports**(インポート)タブから**SillyTavern Import**セクションを探します。説明には「Bring over characters, chats, presets, and lorebooks from SillyTavern files.」と表示されます。

このセクションには、1ファイル用のボタンが4つあります。どれも通常のファイル選択ウィンドウが開くだけで、追加の設定はありません。

- **Import Character (JSON/PNG)**は、`.json`または`.png`のキャラクターカードを取り込みます。
- **Import Chat (JSONL)**は、`.jsonl`のチャット記録を取り込みます。作成されるチャットは常に**Roleplay**で、取り込み後はそのチャットに切り替わります。
- **Import Preset (JSON)**は、`.json`のプリセットファイルを取り込みます。
- **Import Lorebook (JSON)**は、`.json`のWorld Infoファイルを取り込みます。

JSONLは、1行に1件のJSONレコードを書く形式です。SillyTavernがチャット記録を保存するときに使います。

ロアブックが埋め込まれたキャラクターカードをインポートすると、それを独立したMarinaraのロアブックとしても取り込むかどうかをブラウザーが確認します。**OK**をクリックすると、World Infoが単体のロアブックとして残り、他でも使い回せます。**Cancel**をクリックすると、その手順を飛ばしてキャラクターだけを取り込みます。

これらの簡易ボタンはデフォルト設定が固定で、ここでは変更できません。元のタグはすべて引き継ぎ、正規表現スクリプトの適用範囲はキャラクター単位に限定します。正規表現スクリプトとは、AIが文章を受け取る前や受け取った後にテキストを置き換えるルールです。この2つを自分で選びたいときは、代わりに**Characters**パネルの**Import**ボタンを使ってください。詳しくは[キャラクターカードのインポートとエクスポート](../characters/import-export.md)を参照してください。

### モードを指定したチャットのインポート

上で説明した単一ファイル用の**Import Chat (JSONL)**ボタンは、常に**Roleplay**のチャットを作成します。別のモードに取り込みたいときは、チャット一覧の上部にある小さなインポートボタンを使います。ツールチップには**Import SillyTavern or Marinara chat JSONL**と表示されます。このボタンは、そのとき開いているモードのタブ(Conversation、Roleplay、Gameなど)にファイルを取り込みます。チャットのインポートとエクスポート全般については、[チャットのエクスポートとインポート](../chats/export-import.md)を参照してください。

## Import from SillyTavern Folder

このウィザードは、SillyTavernのフォルダー全体をスキャンして、多数の項目を一度にインポートします。キャラクター、チャット、グループチャット、プリセット、ロアブック、背景、ペルソナをまとめて読み込みます。

開くには、**Settings**から**Imports**、**SillyTavern Import**セクションと進み、**Import from SillyTavern Folder**をクリックします。**Import from SillyTavern**というタイトルのウィンドウが開きます。

### ステップ1: SillyTavernフォルダーの指定

1. **SillyTavern Folder Path**欄に、SillyTavernフォルダーのパスを入力します。例えば`/path/to/SillyTavern`のような形です。
2. **Browse**をクリックして、コンピューターのフォルダー選択画面から選ぶこともできます。フォルダー選択画面がないリモートサーバーやヘッドレスサーバーでは、代わりにアプリ内蔵のフォルダーブラウザーが開き、**Select This Folder**ボタンで確定します。
3. 指定するのはSillyTavernのメインフォルダーです。ウィンドウ内のヒントにあるとおり、通常はその中に`data/`や`public/`のフォルダーがあるフォルダーです。
4. **Scan Folder**をクリックします。処理中はボタンの表示が**Scanning...**に変わります。

スキャンが終わると、カテゴリーごとに見つかった件数が表示されます。フォルダーを読み取れなかった場合は、「Could not find SillyTavern data directory.」のようなエラーが表示されます。

### ステップ2: インポートする項目の選択

次の画面のタイトルは**Choose exactly what to import**です。**Characters**、**Chats**、**Group Chats**、**Presets**、**Lorebooks**、**Backgrounds**、**Personas**の各カテゴリーにチェックリストが並び、選択中の件数がカウンターに表示されます。

カテゴリーごとに**All**と**None**のボタンがあり、**Show**と**Hide**のトグルで個々の項目と日付を確認できます。

ほとんどの項目は最初から選択済みです。例外はSillyTavern標準のプリセットで、Marinaraがこれを判別してチェックを外したままにし、その理由をバナーで説明します。対象は`default`、`deterministic`、`neutral`、`universal-*`などの標準プリセットです。どうしてもコピーが必要でない限り、チェックは外したままにしてください。

スキャンでキャラクターが見つかると、次の2つの設定が追加で表示されます。

- **Imported character tags**は、タグの取り込み方を決めます。元のタグをそのまま残すなら**All tags**、タグを取り込まないなら**No tags**、Marinaraに既にあるタグだけを残すなら**Existing only**を選びます。デフォルトは**All tags**です。
- **Imported regex scripts**は、正規表現スクリプトの適用先を決めます。ボットごとに適用するなら**Character only**、すべてのチャットに適用するために**Presets -> Regexes**へ追加するなら**Global**を選びます。デフォルトは**Character only**です。

選択内容に問題がなければ、**Import Selected**をクリックします。フォルダーの手順に戻るときは**Back**をクリックします。

### ステップ3: 進行状況の表示

Marinaraは項目を1つずつインポートします。画面には、スピナー、処理中のカテゴリーと項目名、進行状況バー、カテゴリーごとの件数が表示されます。

### ステップ4: 結果の確認

最後の画面には、成功すると**Import complete!**のバナーが、失敗するとエラーのバナーが表示されます。成功した場合は、カテゴリーごとのカードに最終的な件数が並びます。個別に失敗した項目があると、警告一覧に`Character "Foo": error message`のような行が1件ずつ表示されます。**Done**をクリックするとウィンドウを閉じます。

### ウィザードによるデータの扱い

- インポートは項目単位のベストエフォートです。キャラクター、チャット、プリセット、ロアブック、背景、ペルソナのどれか1件が失敗しても、Marinaraはその項目を飛ばし、警告を記録して残りの処理を続けます。
- 1つのキャラクターに属する複数のチャットファイルは、別々のチャットではなく、1つのチャットの分岐として取り込まれます。
- グループチャットは常に**Roleplay**のチャットとして取り込まれます。
- 取り込んだ項目の日付には、元のファイルの最終更新日をそのまま使います。インポートを実行した時刻にはなりません。

## アクセス権とフォルダーの制限

単一ファイル用のインポートボタンは、追加の設定なしで誰でも使えます。

**Import from SillyTavern Folder**のウィザードはディスク上のファイルを読み取るため、特権アクセスが必要です。サーバーと同じコンピューター(ループバック)からなら、追加の設定なしで動作します。別のデバイスやブラウザーから使う場合は、サーバー側で管理者用のシークレットを設定したうえで、同じ値を**Settings -> Advanced -> Admin Access**に保存する必要があります。シークレットの設定方法は[サーバー設定リファレンス](../CONFIGURATION.md)を参照してください。

サーバーで`IMPORT_ALLOWED_ROOTS`を設定している場合、そのフォルダーの外を指すパスを入力してもMarinaraは受け付けません。**Browse**やアプリ内蔵のフォルダーブラウザーで選んだパスは、この設定が有効でも常に使えます。

## 引き継がれないもの

フォルダーのウィザードがスキャンするのは、上に挙げた7つのカテゴリーだけです。アプリ全体の設定やクイックリプライといった他のSillyTavernのデータは、読み取りもインポートも行いません。

SillyTavern標準のプリセットはデフォルトでチェックが外れているため、自分でチェックしない限り取り込まれません。

変換に失敗した項目は、Marinaraが個別に飛ばします。何が取り込まれなかったかは、ウィザードの最後の画面にある警告一覧で確認できます。
