# Game Mode: HUDウィジェット

このガイドでは、Marinara EngineのGame ModeにおけるHUDウィジェットを説明します。HUDはheads-up displayの略で、ゲーム画面の左右の端に並ぶ小さな情報パネルのことです。ウィジェットの種類、ゲーム開始前の確認ステップ、パネルの移動と固定、ウィジェット構成の共有までを取り上げます。

## HUDウィジェットとは

HUDウィジェットは、ゲーム中の状態を追跡する小さなカスタムパネルです。体力バー、所持金のカウンター、仲間の信頼度などを表示できます。ウィジェットはゲームごとに用意できます。RoleplayのHUDトラッカーとは別の仕組みです。Roleplayのチャットで使うトラッカーの帯については、下の関連ガイドを参照してください。

ウィジェットは合計4つまで作れます。画面の左側と右側への振り分けは自由です。

ウィジェットが使われるのは、そのゲームで**Custom HUD Widgets**(カスタムHUDウィジェット)がオンになっているときだけです。この項目は設定ウィザードでデフォルトでオンになっています。オンの場合、AIのゲームマスター(GM)が世界を組み立てながら、最初のウィジェット一式を設計します。

## 8種類のウィジェット

ウィジェットには8つの種類があります。GMは自分が作る各ウィジェットに種類を選びます。手作業でウィジェットを組み立てるときは、種類を自分で選べます。

| ウィジェットの種類 | 表示される内容 |
|---|---|
| **Progress Bar**(進捗バー) | 体力やスタミナのように、最大値に対する現在値を横棒で表します。 |
| **Gauge**(ゲージ) | 最大値に対する現在値を半円のメーターで表します。 |
| **Relationship Meter**(関係メーター) | 節目のマーカーとラベルが付いたバーです。NPCの信頼度や絆の表示に向いています。 |
| **Counter**(カウンター) | 所持金、経過日数、撃破数のような数値を大きく1つ表示します。 |
| **Stat Block**(ステータス表) | STRやDEX、状態を表す単語など、名前付きの項目と値を小さな表にまとめます。 |
| **List**(リスト) | 進行中の目標のように、短い箇条書きのテキストを並べます。 |
| **Inventory Grid**(インベントリーグリッド) | アイテム枠を格子状に並べます。カテゴリーのタブと個数の表示も付けられます。 |
| **Timer**(タイマー) | 分と秒のカウントダウン時計です。リアルタイムで減らすこともできます。 |

## セッション開始前の確認ウィンドウ

カスタムウィジェットがある場合、最初のターンの前に確認のステップが入ります。**Start Game**(ゲーム開始)を押した時点で**Review Starting Widgets**(開始時ウィジェットの確認)ウィンドウが開きます。ここには開始時のウィジェットがすべて並ぶので、ゲームに確定される前に調整できます。

このウィンドウでできる操作は次のとおりです。

- ウィジェットの**Edit**(編集)を押して、開始時の値を変えたり、**Stat Block**の項目名を付け直したりします。
- **Remove**(削除)を押して、不要なウィジェットを取り除きます。
- **Back**(戻る)を押すと、開始せずにウィンドウを閉じます。
- **Start Game**を押すと、表示されているウィジェットのままプレイを始めます。

進行中のゲームで新しいセッションを始めるときにも、よく似たウィンドウが開きます。こちらのタイトルは**Prepare Next Session Widgets**(次のセッションのウィジェット準備)で、**Start Game**の代わりに**Start Next Session**(次のセッションを開始)ボタンが並びます。閉じるボタンのラベルも**Back**ではなく**Cancel**(キャンセル)です。

## プレイ中にウィジェットを編集する

ゲーム中は、物語の進行に合わせてGMがウィジェットの値を更新します。GMが更新を取りこぼしたときは、手作業で直せます。

1. 画面の左端または右端にあるウィジェットのパネルを探します。
2. ウィジェットのヘッダーにある鉛筆(**Edit**)ボタンをクリックします。
3. 編集ウィンドウで値を変更します。たとえばバーなら**Current value**(現在値)と**Maximum value**(最大値)を設定します。
4. **Save Changes**(変更を保存)をクリックします。

ヘッダーには小さなプラスとマイナスの記号もあります。ヘッダーをクリックすると、ウィジェットの中身を折りたたんだり展開したりできます。

## パネルの移動と固定

ウィジェットのパネルはデフォルトで位置が固定されています。各パネルのヘッダーには鍵アイコンがあります。

1. 鍵アイコンをクリックして固定を解除します。薄い枠線が表示され、移動できる状態になったことがわかります。
2. パネルを好きな位置までドラッグします。
3. もう一度鍵アイコンをクリックすると、その位置で固定されます。

パネルをデフォルトの位置に戻すには、鍵アイコンをダブルクリックするか、アイコンを選択した状態でRキーを押します。位置と固定の状態は、ゲームごとにパネル単位で記憶されます。配置は別のゲームには引き継がれません。

スマートフォンでは、ウィジェットはパネルではなくピル型の小さなボタンとして表示されます。ピルをタップするとそのウィジェットが開き、Xをタップすると閉じます。

## ウィジェットを自分で作る

GMに任せず、ウィジェットを自分で設計することもできます。手動のウィジェットエディターは2か所から開けます。

- ゲームの設定ウィザード: **Custom HUD Widgets**をオンにし、続けて**Build Widget Setup**(ウィジェット構成の作成)トグルをオンにします。トグルの下にエディターが表示されます。
- 進行中のゲーム: **Chat Settings**(チャット設定)を開き、**Widgets**(ウィジェット)セクションを開きます。

エディターでは、ドロップダウンからウィジェットの種類を選んで**Add**(追加)を押します。ウィジェットごとに設定できる項目は次のとおりです。

- **Icon**(アイコン): ヘッダーに表示する短い記号や絵文字。
- **Label**(ラベル): ウィジェットの上部に表示する名前。
- **Type**(種類): 8種類のウィジェットのいずれか。
- **Side**(表示位置): **Left HUD**または**Right HUD**。
- **Accent**(アクセント): ウィジェットの色。

その下には、種類ごとの項目が並びます。バーは**Value**(値)と**Max**(最大)、カウンターは**Count**(カウント)、インベントリーグリッドは**Slots**(枠数)と**Contents**(中身)、タイマーは**Seconds**(秒数)と**Running**(動作中)を使います。エディターには、使える4つのうち何個のウィジェットを使ったかも表示されます。

**Chat Settings**では、**Save Widgets**(ウィジェットの保存)を押すと変更がゲームに反映され、**Reset**(リセット)を押すと未保存の編集を取り消せます。

## インポートとエクスポートでウィジェットを共有する

ウィジェットの構成はファイルに保存して、別のゲームに読み込めます。設定ウィザードにも**Chat Settings**の**Widgets**セクションにも、このためのボタンがあります。

1. **Export Widgets**(ウィジェットのエクスポート)を押すと、現在のウィジェットがJSONファイルとしてダウンロードされます。JSONは、文字だけで書かれたデータ形式です。
2. 別のゲームで**Import Widgets**(ウィジェットのインポート)を押し、そのファイルを選ぶと同じウィジェットを読み込めます。

**Chat Settings**で読み込んだ場合は、インポート後に**Save Widgets**を押すのを忘れないでください。押さないと読み込んだウィジェットが反映されません。
