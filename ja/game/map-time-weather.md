# Game Mode: マップ、時間、天候

このガイドでは、Game Modeのマップパネルと、パーティーを取り巻く世界を追跡する仕組みを説明します。追跡されるのは日付と時刻、天候、そしてパーティーの士気です。マップの表示形式、移動と拡大縮小の操作、日付と時刻を手動で設定する方法がわかります。

## マップパネル

Game Modeでは、ゲーム画面に小さなマップパネルが表示されます。パネルには現在のマップ名、ゲーム内の日付、時間帯を表す空模様のアイコンが並びます。

コンピューターでは、マップは画面に組み込まれたパネルとして表示され、ひと目で確認できます。スマートフォンでは、左上のマップアイコンをタップします。ボタンのラベルは**Open map**(マップを開く)で、ポップオーバーでマップが開きます。

パネルはドラッグして移動でき、位置を固定することもできます。ドラッグできるパネルの仕組みについては、下のリンクにあるHUDウィジェットのガイドを参照してください。

## grid表示とnode表示

マップには2種類の表示形式があります。どちらを使うかは、そのマップが表す場所の種類に応じてMarinara Engineが選びます。手動で切り替えることはできません。

- **grid**表示は、オーバーワールド、地方、街のような開けた場所に使われます。草原、森、水、山、砂漠、雪原、町、道、洞窟といった地形ごとに色分けされたマス目で表示されます。
- **node**表示は、ダンジョンや屋内のような閉じた場所に使われます。各地点が円で表示され、線でつながります。まだ発見していない地点には疑問符のアイコンが付きます。破線はまだ通っていない経路、実線は通ったことのある経路を表します。

## パーティーの移動

移動するには、マップ上の場所を選びます。選べる場所は限られています。gridマップでは、パーティーの隣にあり、かつすでに発見済みのマスだけを選べます。nodeマップでは、現在地とつながっているノード、またはすでに発見済みのノードだけを選べます。それ以外のマスやノードはクリックしても何も起こりません。

1. gridのマスをクリックするか、nodeマップのノードをクリックします。
2. メッセージ入力欄の上に、場所の名前が入った**Destination:**(目的地)のチップが表示されます。
3. メッセージを入力して送信します。Marinaraがメッセージの先頭に`*moves to <place>*`のような短い一文を追加します。

取り消すには、**Destination:**のチップにある小さなクリアボタン(X)をクリックします。

スマートフォンでは操作が少し異なります。ノードを1回タップして選択し、フッターの**Set destination**(目的地を設定)をタップします。**You are here**と表示されているノードが現在地です。

## マップの拡大と縮小

どのマップにも右上に拡大縮小のボタンがあります。

- 近づいて見るには**Zoom in**(拡大)、つまりプラスのボタンをクリックします。
- 広い範囲を見るには**Zoom out**(縮小)、つまりマイナスのボタンをクリックします。

倍率は75%から180%まで、25%刻みで変わります。

## マップの切り替え

ゲームによっては、マップや地方が複数あります。マップが2つ以上ある場合は、マップパネルの上部に小さなドロップダウンが表示されます。ここから別のマップを表示できます。実際に今いるマップには**(Current)**が付きます。

## 新しいマップの生成

マップパネルの左上には**Generate another map**(別のマップを生成)というラベルの杖のボタンがあります。クリックすると、現在のマップが新しいマップに置き換わります。

まだマップがないゲームでは、パネルに**No map yet**と表示され、同じ動作をする**Generate**(生成)ボタンが並びます。

## 日付と時刻を手動で設定する

日付と時刻のコントロールは、マップパネルの上部にあります。**Day**(日)という表示と数字、そして時間帯を表す小さな空模様のアイコンが並びます。

1. **Day**のコントロールをクリックします。
2. 欄に新しい日付の数字を入力します。指定できるのは1から9999までです。
3. ドロップダウンから時刻を選びます。選択肢は**Dawn**、**Morning**、**Afternoon**、**Evening**、**Night**、**Midnight**です。
4. 欄の外をクリックするか、Enterを押すと保存されます。

これは手動での上書きです。次に説明する自動の時計とは別に、日付と時刻を自分で決められます。時計は自動で**Noon**を表示することもありますが、Noonは手動の選択肢には含まれません。

## 時間が自動で進む仕組み

ゲーム内の時計は自動で進みます。AIではなく決まった計算で動くので、結果は常に一貫しています。新しいゲームはどれもDay 1の朝8時から始まります。行動を取るたびに、決まった分だけ時計が進みます。

| 行動 | 進む時間 |
|---|---|
| 会話 | 15分 |
| 探索 | 30分 |
| 戦闘1ラウンド | 5分 |
| 短い休息 | 1時間 |
| 長い休息 | 8時間 |
| 移動 | 2時間 |

時計が深夜0時を回ると、日付の数字が1つ増えます。

## 天候

天候もAIを使わず、決まった計算で自動的に管理されます。天候はバイオームと季節で決まります。バイオームとは、砂漠、寒冷地、沿岸、山岳のように、パーティーがいる場所の種類のことです。天候には晴れ、曇り、雨、嵐、雪、吹雪、霧、砂嵐などがあります。

天候は行動によって変わることがあります。移動したときと長い休息を取ったときにいちばん変わりやすく、探索したときにも変わることがあります。それ以外ではめったに変わりません。天候は、ゲームマスター(GM)が各シーンを描写するときの雰囲気に反映されます。

天候を画面に表示するには、アプリの外観の設定で**Dynamic weather effects (rain, snow, fog, etc.)**(天候エフェクト)をオンにします。デフォルトではオンです。オンにすると、雨、雪、霧などの粒子アニメーションがゲーム画面の上に重なって表示されます。表示内容は現在の天候と時刻に合わせて変わります。表示に関するそのほかの設定は、下のリンクにある外観の設定のガイドを参照してください。

## パーティーの士気

ゲームは0から100までのパーティーの士気を、画面に出さない形で管理しています。士気には低い順にBroken、Low、Steady、High、Inspiredの5段階があります。

士気は物語の展開に応じて変動します。戦闘に勝つ、クエストを達成する、宝物を見つけるといった出来事で上がります。戦闘に負ける、クエストに失敗する、仲間を失うといった出来事で下がります。時間が経つと、士気は中間の値へ戻っていきます。

士気はゲーム内に数値としては表示されず、裏側で働きます。ダイスロールの結果に影響し、Inspiredでは+2、Brokenでは-2の補正がかかります。また、ゲームマスター(GM)がパーティーの雰囲気を描写する際の色合いも変わります。
