# Game Mode: ダイスとスキル判定

このガイドでは、Marinara EngineのGame Modeでダイスを振る方法を説明します。クイックダイスメニュー、独自のダイス記法、独自のダイスロールにかかる上限を取り上げます。さらに、ゲームマスター(GM)が難易度(DC)に対してスキル判定を行う仕組みも説明します。

## ダイスを振る

Game Modeのチャットでは、メッセージ入力バーにダイスボタンがあります。ボタンにカーソルを合わせると**Roll dice**(ダイスを振る)というヒントが表示されます。クリックするとクイックダイスメニューが開きます。

メニューには、1クリックで使えるプリセットが8つあります。

| プリセット | 振るダイス |
|---|---|
| d20 | 20面ダイス1個 |
| d6 | 6面ダイス1個 |
| 2d6 | 6面ダイス2個 |
| d10 | 10面ダイス1個 |
| d100 | 100面ダイス1個 |
| d4 | 4面ダイス1個 |
| d8 | 8面ダイス1個 |
| d12 | 12面ダイス1個 |

手早くダイスを振る手順は次のとおりです。

1. Game Modeのチャットでメッセージ入力バーを開きます。
2. ダイスボタンをクリックします。
3. 8つのプリセットのどれか、たとえば**d20**をクリックします。
4. 入力バーに`🎲 d20`のような小さなチップが表示されます。

ダイスロールはすぐには送信されません。いったん予約された状態になります。予約を取り消すときは、チップにある消去ボタンをクリックします。このボタンのヒントは**Clear queued roll**(予約したダイスロールの取り消し)です。

ダイスの計算は、次のメッセージを送信したときに実行されます。結果はタグとしてメッセージの末尾に追加されます。ボーナスなしでダイスを1個だけ振ると、次のような形になります。

```
[dice: d20 = 14]
```

ダイスが2個以上ある場合やボーナスが付く場合は、内訳も表示されます。

```
[dice: 3d8+2 = 18 (4, 6, 6 +2)]
```

ゲームマスターはこのタグを読み取り、結果に沿って物語を進めます。

## 独自のダイス記法

ダイスメニューには、独自のダイスロールを入力するテキスト欄もあります。記法は一般的な`NdM`形式です。`N`は振るダイスの個数、`M`は1個あたりの面数を表します。末尾にボーナスやペナルティーを付けることもできます。

欄のプレースホルダーには`3d8+2`という例が表示されます。これは8面ダイスを3個振り、合計に2を足すという意味です。

独自のダイスロールを使う手順は次のとおりです。

1. ダイスボタンをクリックしてメニューを開きます。
2. テキスト欄に記法を入力します。たとえば`2d6+1`です。
3. Enterを押すか、欄の横にある紙飛行機の形をした送信ボタンをクリックします。
4. ダイスロールがチップとして予約され、送信できる状態になります。

入力できる例をもう少し挙げます。

- `d20`は20面ダイスを1個振ります。
- `4d8-1`は8面ダイスを4個振り、合計から1を引きます。
- `2d6+3`は6面ダイスを2個振り、合計に3を足します。

上限は2つあります。一度に振れるダイスは100個まで、1個あたりの面数は1000までです。これを超える指定をしても、拒否されるのではなく、上限に収まるように切り詰められます。入力が`NdM`記法として正しくない場合はダイスロールが失敗し、期待される形式を示すエラーが表示されます。

## スキル判定

スキル判定は、忍び足、手がかりの発見、NPCの説得のように、失敗の可能性がある行動が成功するかどうかを決めるものです。スキル判定を自分から始めることはできません。ゲームマスターが物語の中で判定を求め、アプリがそれをアニメーション付きのd20のダイスロールと結果バナーに変えます。

バナーにはスキル名と目標値が表示されます。たとえば**Stealth Check**の隣に**DC 15**と出ます。DCはDifficulty Class(難易度)の略で、ダイスロールが到達すべき数値です。

### 結果の決まり方

判定では20面ダイスを1個振り、次の2つの修正値を足します。

- スキル修正値。ゲームがそのキャラクターについて記録しているスキルレベルから決まります。そのスキルのレベルがまだない場合、修正値は0です。
- 能力値修正値。そのスキルに対応する能力値から決まります。

ダイスの目に2つの修正値を足した数が合計値です。合計値がDC以上なら判定は成功、届かなければ失敗です。どのスキルがどの能力値に対応するかは自動的に決まります。たとえばStealthはDexterity、PerceptionはWisdom、PersuasionはCharismaを使います。アプリが認識できないスキルはIntelligenceとして扱われます。

### クリティカル成功とクリティカル失敗

次の2つの出目は、計算結果より優先されます。

- ナチュラル20(ダイスの目そのものが20)は**CRITICAL SUCCESS**(クリティカル成功)です。DCがどれほど高くても必ず成功します。
- ナチュラル1(ダイスの目そのものが1)は**CRITICAL FAILURE**(クリティカル失敗)です。修正値がどれほど大きくても必ず失敗します。

バナーには**CRITICAL SUCCESS**、**SUCCESS**、**FAILURE**、**CRITICAL FAILURE**の4つのうち1つが表示されます。

### アドバンテージとディスアドバンテージ

ゲームマスターは、アドバンテージ付きまたはディスアドバンテージ付きで判定を求めることもできます。両方が同時に付くことはありません。

- アドバンテージ付きの場合、アプリは20面ダイスを2個振り、大きいほうの目を採用します。
- ディスアドバンテージ付きの場合、アプリはダイスを2個振り、小さいほうの目を採用します。

どちらかが有効なときは、バナーのDCの隣にその状態が表示され、どちらのダイスを使ったかも示されます。

### ダイスを先に振っておく

判定が発生する前に、ダイスメニューから`d20`を予約しておくこともできます。予約しておくと、スキル判定は新しくダイスを振らず、予約した出目をそのまま使います。スキル修正値と能力値修正値は、その出目に対して同じように加算されます。
